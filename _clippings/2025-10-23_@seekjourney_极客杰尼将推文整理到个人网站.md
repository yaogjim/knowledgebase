**极客杰尼** @seekjourney 2025-10-17

我用云端 Codex 把过去一年的长推文整理到了个人网站上，效率相当高！

怎么做到的？

1\. 使用 Yangyi 老师的推文下载工具，输入账号名称，时间范围1年，执行时间大概在10-15分钟（取决推文数量）

2\. 下载推文 JSON 数据，推送到 Github

3\. 云端 Codex 连接 Github 仓库，布置开发任务

4\. 提示词细节，按周整理数据，过滤短推文/重复引用推文

要注意什么？

1\. 云端 Codex 需要开 GPT Plus 及以上

2\. Codex 授权访问 Github

3\. Github 配置自动化部署到 Vercel
