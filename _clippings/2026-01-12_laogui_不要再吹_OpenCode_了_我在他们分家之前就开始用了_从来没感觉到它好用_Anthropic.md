# 不要再吹 OpenCode 了，我在他们分家之前就开始用了，从来没感觉到它好用。Anthropic

**老鬼** @laogui [2026-01-11](https://x.com/laogui/status/2010242888408465622)

不要再吹 OpenCode 了，我在他们分家之前就开始用了，从来没感觉到它好用。Anthropic 封堵 OpenCode，我相信还有一个原因：OpenCode 不如 Claude Code 好，影响人家模型的口碑。

如果你真的在找一个可以匹敌 Claude Code，还支持 BYOK 的编程工具，我更推荐 Droid，虽然不开源，但支持多家模型，也可以使用自己的 Key。这是目前唯一一个可以匹敌 Claude Code 的工具，比 Codex，Gemini cli 都强。在新技术的支持上也非常及时，第一时间就支持 Subagent，Skills。

我现在遇到一些很复杂的任务，如果对 Claude Code 的结果不太满意，就换成 Droid 再做一遍，经常给我带来惊喜。相信 @iamzhihui 比我更有发言权，他宁愿放弃 Clauce Max 转向 Droid 的 $200/月套餐。

Droid 的强项是上下文工程管理做的好，它有一套多层“上下文栈”，把工具组织好的一切信息逐步蒸馏成“当前任务刚好需要的内容”。Droid 优秀的环境引导机制、对工具输出的结构化解析，以及在规划阶段的严谨性，使其在处理复杂、多步骤的任务时不仅能为 LLM “写出”正确的命令，更能正确地“执行”和“纠错” 。

我在使用 Claude Code 的 Plan 模式的时候，在后面执行的时候偶尔会超出它“规划”的范围，而 Droid 从来没遇到过。

Factory Droid 官方的套餐比较贵，每月 $20 的套餐高强度用一天能用完。我继续“顶风作案”，给大家推荐一个“不合规”的反代工具，把 Claude Code, ChatGPT, Gemini cli, Antigravity 的订阅反代给 Droid 使用，GitHub：automazeio/vibeproxy。当然最近出的 Antigravity Tools 也可以，只要能转成 OpenAI，Anthropic API 都支持。
