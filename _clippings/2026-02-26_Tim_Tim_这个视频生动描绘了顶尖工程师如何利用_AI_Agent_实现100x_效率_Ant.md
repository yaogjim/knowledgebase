# Tim 这个视频生动描绘了顶尖工程师如何利用 AI Agent 实现100x 效率： Ant

**Tim**

这个视频生动描绘了顶尖工程师如何利用 AI Agent 实现100x 效率： Anthropic 的一位工程师写好了一份技术规范（Spec），把 Claude 接入 Asana 任务板，然后就下班回家了。Claude 随后将这份 Spec 拆解成了具体的工单，并为每个任务派生出相应的 AI Agent，它们开始独立进行开发。 当 Agent 遇到困惑时，它会自动运行 git-blame 溯源，并在 Slack 上发消息给对应的工程师请教。到了周一，这些 Agent 已经完成了整个插件功能的开发。 这就是目前顶尖工程师交付软件的一个缩影。 开发者很快就能同时编排 50 个 AI Agent 并行工作。届时，优秀工程师与卓越工程师的分水岭，将在于对 Spec（需求规范）的定义能力。 如果你不能从底层深度理解你要构建的产品，你就无法写出一份在如此规模下依然经得起推敲的 Spec。 那些深谙底层原理、擅长架构设计，并能高效编排 Agent 的下一代开发者，将成为真正的 “1000 倍程序员”（1000x Developer）！
