# Claude Code 的最佳搭档：happy！随时随地访问家里或者服务器上的 Claude Cod

**weishu** @twsxtd [2025-12-02](https://x.com/twsxtd/status/1995826728972026168)

Claude Code 的最佳搭档：happy！随时随地访问家里或者服务器上的 Claude Code 写代码，iPad 手机都能使，不要太方便！以前我也尝试过各种远程访问 Claude Code 的方案：

1\. macmini 用 tmux 跑 Claude Code，然后 tailscale / cloudflare tunnel ssh 连上去 + tmux，可惜 tmux 对触摸屏支持不友好，通知还要自己搞定。

2\. Claude Code + Telegram Bot，直接把各种操作封装到机器人操作，但是很可惜，大部分项目完成度都很低。

3\. claudecodeui，纯 web 封装，实现了文件管理和 git，但是用起来不方便，只有 yolo 模式，动不动断连。

当我用了 happy 才知道那是真的 happy，家里运行个 daemon，外出打开手机就能直接干活，AI 干活的时候你可以去散散步看看风景，干完以后直接给你发 iOS push 通知！

有了 happy，iPad mini 又要可以当最佳开发机了！
