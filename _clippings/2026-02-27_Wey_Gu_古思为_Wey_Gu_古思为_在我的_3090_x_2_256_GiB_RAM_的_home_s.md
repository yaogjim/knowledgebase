# Wey Gu 古思为 在我的 3090 x 2 + 256 GiB RAM 的 home s

**Wey Gu 古思为**

在我的 3090 x 2 + 256 GiB RAM 的 home server 上，跑 Qwen3.5-397B-A17B 的 4bit 量化，offload CPU，能做到大概 7~10 token/s 的 decoding，感觉很 sweet 啊 这让我觉得 minimax m2.5 量化也可能跑了，等我也试试！
