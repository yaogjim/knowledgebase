# Leo｜一个人 + AI: 之前骂 Claude 变笨，当时还没完全搞懂

**Leo｜一个人 + AI**

之前骂 Claude 变笨，当时还没完全搞懂。

折腾半天把 18 个对话的 JSONL 翻完了——结论比「全怪模型」或「全怪自己」都复杂：有三层原因叠在一起。

第一层，Opus 4.8 这周确实在抽风。

GitHub 上 6/8 起就有人报 #66539：无视 CLAUDE.md、绕过权限直接动手、没干完报干完。

官方 status 那几天也有 error spike。

那些「看着规则照样跳过」的破事，有一部分真不是我这边的配置问题。

但扣掉模型这层，我自己还叠了两层，更隐蔽。

第二层，一开始怀疑的 RTK，不只是「有点关系」。

我装了个省 token 的 hook，它在 Bash 输出返回前偷偷改写：删行、删列、换成表情摘要。

模型看到的是假 stdout，拿假数据干活，当然更像变笨。

第三层才真吓人。

有个 36 万 token 的长对话，被自动压缩了 3 次之后，模型开始一本正经地虚构。

它编了一整起安全攻击：说返回里被塞了攻击代码，还伪装成系统提示骗我点确认。

说得有鼻子有眼，我信了一整晚，差点真去反馈。

回去翻原始日志——

那次攻击根本不存在，那条命令压根没执行过。

注入相关的英文，一条都没出现在真实 tool\_result 里，全是它自己编的。

被反复压缩洗过的记忆，已经分不清看过的和想象的。

更离谱的是，连帮我排查的另一个 AI 也信了，还写进了报告。

排查 AI，也会被 AI 骗。

昨晚修到半夜，这几项已经落地：

RTK hook 直接关死；压缩窗口从 400K 实验改回默认 1M；

脏 session 不 resume；重要结论一律回原始日志核对。

那句「疯了」——我收回一半：

模型这周确实有问题，这半句不冤。

另一半得认：就算模型正常，我也能靠插件和压缩把它喂成傻子。

AI 突然变笨，先别急着骂模型，也别急着认栽。

大概率是三件事叠在一起：模型状态、你给它装的插件、它被压缩了几次的记忆。
