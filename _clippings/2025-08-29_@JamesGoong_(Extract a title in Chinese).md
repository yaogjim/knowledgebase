Claude Code 使用技巧 5/n

当一个对话的上下文快达到上限，触发auto-compact 之前，可以直接问 Claude Code 新的对话应该怎样才能更好的继续当前任务。

“我看到 Claude Code 的上下文还有 2% 就会触发 auto compact。基于我现在专注的任务，我的 PLAN 和 Active Progress，如果我要在新的 Claude Code 对话中进行下一个相关 xxx 任务，我应该怎么做？”

最了解 CC 的还是 CC 自己，“原汤化原食”
