人生下半场，我一定要坚持做好个人IP  
  
过去 20 年，如果让我选一个最后悔的事情，绝对不是错过 BTC，而是没有坚持做个人 IP。未来 20 年，我想我一定会坚持把个人 IP 做到底。  
  
现在很多人一说到个人 IP，想到的是知识付费，想到的是赚钱，但是我觉得长期坚持做好个人 IP，有远远比单纯的赚点钱更大的价值：就是鞭策自己不断的成长，并且在成长的道路上，认识更多的同道。  
  
2003 年，当我最开始在网上论坛发帖的时候，我只是一个普通的不能再普通的、互联网行业的程序员而已。但是，我的整个人生轨迹从那一刻开始，已经被改变了。  
  
当时呢，我在自学一个非常小众的开源软件，Hibernate，国内知道的人很少。我只能自己翻看官方网站上的技术文档，官网当时也很山寨，文档也不像现在这样丰富。非常偶然的一个机会，我在一个技术论坛上，看到有人发了一篇介绍 Hibernate 的帖子，他的观点实在是太对我的胃口。关键是，茫茫人海中，竟然能找到一个可以交流这么小众软件的人，瞬间内心引为知己。  
  
我就回复了那篇帖子，写了非常长的一篇回帖，把自己的观点和主要的心得都事无巨细写了出来。我们两个人就在技术论坛里面热烈的讨论了起来，逐渐开始有其他人也加入了讨论。这个讨论贴估计跟帖了上百条吧，中间有好多非常深入的技术讨论。这是一个奇妙的开端，从这个长长的讨论贴开始，我就在这个技术论坛上经常和别人交流技术，也解答一些技术问题，前后大概三四个月，就成了技术论坛的大 V。  
  
但是好景不长，我鼓吹的开源软件在 2003 年过于离经叛道，被论坛给删帖，我还被禁言了。一怒之下，我就自己搭建了技术论坛，这就是我第一次创业的起源。既然自己撸起袖子搭网站，肯定要全力以赴好好干呀，所以一开始真的是废寝忘食啊，恨不得除了吃饭和睡觉的时间，都泡在论坛里面发帖和回帖，网站上每一个发过贴的 ID 我都记得清清楚楚。  
  
我一直认为，我只是一个技术水平还不错，代码风格干净的程序员而已，估计和后来那些互联网大厂的核心技术骨干还是有很大差距的。但是在做网站的过程中，逐渐聚集起来了越来越多优秀的技术人员，他们也在论坛里面热烈的交流，贡献了很多非常精彩的讨论，启发和影响了国内越来越多的程序员。 JavaEye 逐渐成了国内最早也是最大的推广开源软件技术的社区。  
  
在当时，我自己并不知道 JavaEye 有那么高的知名度。作为一个网站的站长，每天都会看网站所有的内容，每天自己大量的输出内容，我单纯觉得在 JavaEye 这个高手云集的社区里面，自己成长得特别快，无论是技术水平还是技术格局和认知层次。我必须承认那是我成长最快的人生阶段，无论是技术水平，还是写作能力，抑或是创业的经验。  
  
回过头去想，虽然现在 BBS 论坛这种产品形态已经成为过去时了，如今都是视频主播的订阅和信息流产品形态，但是内核并没有改变：通过输出内容这种方式，和别人进行充分的交流，这是让自己成长最快的方式，也是最好的社交方式。  
  
2003-2010 年虽然我在创业做网站，但我想本质上和运营个人 IP 有很多相同点，或者说我本人就是中国互联网第一代的个人 IP 的受益者之一吧。  
  
2010 年，当我选择把 JavaEye 卖给 CSDN，并且担任 CSDN CTO 的时候，我总结自己创业没有取得更高成绩的原因： 我太擅长单打独斗，却不擅长带领团队。创业期间一度合伙人离开，我要自己一个人支撑的窘境。所以从加入 CSDN 那一天起，我就暗暗下定决心，我一定要把自己带团队的能力培养出来。我未来一定要二次创业，取得更高的成就。  
  
所以我放弃了经营个人 IP，也很少在社区和博客更新内容。我幼稚的认为：这些都不重要，重要的是我要凭借自己的产品，技术和运营能力帮助 CSDN 更上一层楼，还要锻炼自己的领导力。我加入 CSDN 之前，就很坦率的对当时的 CEO 说，我加入 CSDN 的目标，就是希望成为下一任 CEO。  
  
2012 年微信公众号刚刚推出的时候，我就高度看好这个借鉴了 RSS 订阅机制的新媒体平台。2013 年我还建议产品下属去运营自己的微信公众号，然后她只花了一两个月，天天转载文章，就做成了一个 6 万+ 粉丝的公众号。  
  
但是我自己没去做。我错误的认为对于一个志在移动互联网浪潮创业的人，天天在公众号上写文章，那不是我该干的正事。2013 年底我离开了 CSDN，再次创业搞亲子，但是没有成功，随后 2015 年加入了丁香园。  
  
当我复盘 2012-2015 年这段人生的经历，我觉得我完全抛弃了第一次创业的成功原因：

2003-2010 年，正是因为我坚持输出优质内容，做好了个人 IP，我才成功的；

2012-2015 年，正是因为我放弃了做个人 IP ，才完美的错过了微信公众号最早的红利期；  
  
特别是当我 2015 年加入丁香园之后，才震惊的发现，原来这家公司绝大部分的流量，以及基于流量的生意都来自于微信公众号的海量粉丝。毫不夸张的说，要不是因为如此重视经营，且投流占领微信公众号渠道，并且长期处于公众号排名的前几位，丁香园根本不可能取得后面的成就。  
  
说到这里，可能你会产生疑问，既然都后知后觉，意识到做个人 IP 的重要性了，为什么后面没有去好好经营微信公众号呢？即便 2018 年开始写微信公众号都不算晚啊？  
  
原因很简单：因为有一些不好的前车之鉴，公司创始人非常忌讳高管经营个人知名度。甚至曾经有过内部规定，要求高管出席外部会议演讲的内容，都要向公司报备。既然还是打算待下去，希望公司有上市的那一天，两者不可兼得，只好放弃经营微信公众号。  
  
2020 年春节，疫情在家办公，我们火速上线了国内最早的疫情地图，也确实一炮打响。其实我觉得上线一个地图，还是不够的，还应该基于疫情数据，每天提供分析报告和独特的观点。既然无法说服公司去做，我就自己做了几期疫情数据分析和疫情预测的短视频，发布到了抖音上，也挺受欢迎的。  
  
2020 年初是做抖音特别好的窗口期，当时起来了一大批抖音的 KOL。但是我尝试做了几期疫情分析的短视频就放弃了，原因也超级简单：感受到了来自公司同事强大的社交压力。你说你上班一坐到办公室，就有同事笑嘻嘻过来和你打招呼：范老师，我看了你昨天发的短视频了，真的很不错呀。那笑容可能是真心的，但是在那个环境下，给我的感受就是：你一个 CTO 不务正业，天天去搞什么短视频啊？  
  
这一放下就是两年时间。2022 年上海封城，我在杭州上班，周末闲来无事。又琢磨着做微信视频号。因为 2022 年，是个人都能看出来微信公众号的时代已经结束了，为了应对抖音的竞争，微信大力推广视频号，这是视频号最好的红利期。而且我也十分不理解为什么公司还躺在公众号的功劳簿上，不去积极开拓短视频。然而当我尝试着做了几期短视频之后，好事的同事们又笑嘻嘻的找上门了。哎，一声叹息，再次放弃了经营个人 IP。  
  
所以，除非自己是老板，否则在中国，打工和做个人 IP 看起来就注定是互相冲突，无法共存的。至于期间利弊得失，只能每个人自己去衡量了。  
  
回顾 2015-2023 年这整整 8 年，期间经历了微信公众号，抖音，微信视频号的发展期，我都错过了。如果复盘从 2012-2024 年这十几年的历史，正好是中国互联网个人 IP 和 KOL 蓬勃发展的黄金时代。如果要创业，没有什么是比做好个人 IP 更好的创业方式了。 即便想要创业做软件产品，你也离不开靠个人 IP 获取流量和投资啊？  
  
我想，2010 年之前我之所以能成功，本质上还是离不开持续输出内容，打造个人 IP 上。不仅仅收获个人成长，也是最好的品牌打造的方式；2010 年之后，或主动或被迫的放弃持续输出内容之后，就再也无法回到主流赛道上来了。  
  
2026 年，我将年满 50 岁，人生进入了下半场，也被迫进入了转型期，必须调整心态，认识到一个残酷的现实：这个世界的中心是年轻人的，老登不管愿意不愿意，都要把舞台让出来。成功还是失败，已经不是我这代人应该考虑的了。但是我希望自己终身都能保持学习的激情和成长的心态，人生的乐趣不就是不断的进步和面对有趣的挑战吗？  
  
2026 年，我想把自己清零，就当自己是一个没有工作经验的自雇人士，重新出发：  
  
第一，从头开始做好个人 IP，记录人生的二次成长，作为独立开发者，做点有趣的 AI 产品；

第二，2025 年我申请了香港高才，也考取了保险代理牌照，2026 年我要努力转型成为一个成功的财务策划顾问；  
  
人生下半场，我来了！
