Vibe Coding 之一句话解决 Claude 频繁创建说明文档问题 每个人使用 Claude 写代码时，应该都遇到了说明文档越来越多的问题。 其实只需要下面的一个小操作就能解决![👇🏻](https://abs-0.twimg.com/emoji/v2/svg/1f447-1f3fb.svg "Down pointing backhand index") 将如下 Prompt 写入 [http://CLAUDE.md](https://t.co/sRanKUAPLg) 中 “默认情况下，不要创建任何新的说明文档或文档文件。 不要自动生成 [http://README.md](https://t.co/OlRqWAsoCj)、设计文档、使用说明、架构说明等。 只有在我明确要求“编写文档 / 生成 README / 写说明文档”时，才允许创建或修改文档。 避免输出与代码无关的说明性文档”
