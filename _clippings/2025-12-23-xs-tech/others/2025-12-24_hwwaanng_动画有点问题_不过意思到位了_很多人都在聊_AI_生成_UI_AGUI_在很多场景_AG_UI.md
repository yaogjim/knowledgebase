# 动画有点问题，不过意思到位了。 很多人都在聊 AI 生成 UI，AGUI。 在很多场景 AG-UI

**Hwang** @hwwaanng 2025-12-23

动画有点问题，不过意思到位了。

很多人都在聊 AI 生成 UI，AGUI。

在很多场景 AG-UI 都有各种边边角角的问题，但是在表单填写这个 case 上， AI 生成的表单可用性相当之高了。

在 input 区域，根据 Skill/或者 Agent 的功能，让 AI 生成一组表单 UI 让用户能够跟规范的输入，让普通用户不知不觉中组织出更好的上下文，我觉得还是非常有戏的。
