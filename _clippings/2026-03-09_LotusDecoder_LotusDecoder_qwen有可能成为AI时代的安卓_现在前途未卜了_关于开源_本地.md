# LotusDecoder qwen有可能成为AI时代的安卓，现在前途未卜了。 关于开源、本地

**LotusDecoder**

qwen有可能成为AI时代的安卓，现在前途未卜了。 关于开源、本地、端侧 model， 我还是坚定地认为未来是一个很大的潜力市场的， 首先，每人都有自己隐私数据和即时需求， 需要AI和agent 处理的。 例如病历和体检报告，每家AI公司都上传给他们， 他们拿去干了啥，没有保管好泄密了，这些都很多风险点。 冰箱、空调有一定的环境感知和自主调节，24小时在线做细微的功能调节，用一块小芯片推理，重大异常情况才上报给主机级的agent，主机处理不了，再上报云端。从效率和成本考虑，可能都会这样演变。 其次，是生态多样性，整个市场只有一个云端闭源巨无霸，管理一切，从森林火灾、生物生态的理论来说，单点故障会波及太大了，前几天的亚马逊机房导致claude断线很说明问题了。多种多样的model ，才可能避免单点bug 或 攻击导致大范围的故障和灾害。 最后，非对称竞争性领域的 AI 和 agent， 也不大会一个行业只用一个 model ，或同一套 model，还是会各自挑选和组合，尤其是民用领域，一个可以自己微调、改造的 AI model ，在整体性能低于闭源，但是具体落地业务特别垂直和精准，优势也是很大的。 当然对于 QWEN 来说，如果可以坚持到，茫茫多的本地部署、智能设备都是 qwen 开源model，那么 qwen 像安卓一样，可以掌握了绝大多数ai 和 agent 的底层信息入口，其model 本身输出时对 阿里的各项服务排在前面，首选推荐，正面意义很大。从风险面来看，现在围绕 transfomer 建立的优势，也很可能会有新的范式所替代，面临着过去的积累都是沉没成本。 所以总得来说，阿里很现实，qwen也实在。
