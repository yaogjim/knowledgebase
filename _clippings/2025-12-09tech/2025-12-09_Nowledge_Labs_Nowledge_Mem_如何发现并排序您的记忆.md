# Nowledge Mem 如何发现并排序您的记忆

Nowledge Mem 如何发现并排序您的记忆

本页说明 Nowledge Mem 中的搜索机制：我们如何寻找匹配的记忆片段、按相关度排序，并从您的使用习惯中持续学习。

## 评分流水线

当你搜索时，Nowledge Mem 不仅匹配关键词，还会综合多重信号来呈现最有用的结果。

![Nowledge Mem Scoring Pipeline](/_next/static/media/scoring-pipeline.2a1948b0.webp)

Nowledge Mem Scoring Pipeline

### Semantic Scoring

本轨道将为您寻找与您需求相匹配的记忆片段：

- **语义搜索** ：通过语义相似性查找记忆，而非仅依赖精确词汇匹配。搜索"设计模式"即可找到关于"架构方法"的相关记忆。
- **关键词搜索** ：通过 BM25 排序算法精准捕捉特定短语与技术术语。
- **标签匹配** ：显示带有对应标签的记忆片段。
- **图遍历** ：通过实体和主题社群发现关联记忆。

### 衰减与时效评分

此轨道根据新鲜度及您的使用情况调整结果：

- **时效性** ：近期被访问的记忆会获得更高评分。我们采用指数衰减模型，半衰期约为 30 天。
- **访问频率** ：反复调用的记忆会变得更加牢固（遵循对数缩放规律，存在边际效益递减）。
- **重要性下限** ：高重要性记忆即使未被使用，其可访问性也始终维持在最低阈值之上。
- **时间匹配** ：提升事件时间与查询相匹配的记忆权重（仅限深度模式）。

这些评分项综合成一个最终分数，用于决定结果的排序。

## Memory Decay

记忆会随时间自然消退，除非你通过使用来强化它们。

### How It Works

**时效性** ：昨天访问的记忆比三个月前的记忆得分高得多。30 天的半衰期意味着，若未访问，得分大约每月减半。

**频率** ：第十次接触记忆比第一百次更重要。这映射了人类记忆的工作方式：早期重复建立持久性，后续重复则收益递减。

**重要性底线** ：标记为高重要度的记忆永不彻底衰退。即便未被触及，它们仍保持最低可访问性。这项机制守护着基础知识免于消逝。

### What This Means

- 活跃的知识常保鲜活
- 旧忆不曾消逝，只是在同等关联度下排序靠后
- 重要的知识不会因访问模式而改变
- 系统会根据您的行为自动学习

## 时间理解

Nowledge Mem 理解两种时间概念。

### 事件时间与记录时间

**事件时间** 是指事件实际发生的时刻：

- 2020年产品发布会
- 上季度决策
- 在我们迁移之前

**记录时间** 指的是你保存记忆的时刻。你可能今天记录了一个关于 2020 年事件的记忆。

对于“关于2020年事件的近期记忆”这类查询至关重要：你最近保存的（记录时间）关于2020年事件（事件时间）的内容。

### 时间意图检测

在深度模式下，系统会解析时间相关的表述：

| Query | Understanding |
| --- | --- |
| 2023年的决策 | Event time: 2023 |
| "Recent memories" | Record time: recent |
| 关于2020年的近期记忆 | 事件：2020年，记录：近期 |
| 迁移前 | 事件：在此之前 |

诸如“上个季度”、“2020年左右”或“今年年初”这类模糊表述，会被转化为具有实际意义的筛选条件。

### Date Precision

当你保存关于"2020年初"的记忆时，系统会：

1.  规范化为可搜索的日期格式（2020-01-01）
2.  追踪精度级别（年、月或日）
3.  保留原意以精确匹配

这使得"2020年的记忆"（年份精度）与"2020年1月的记忆"（月份精度）能够实现差异化运作。

## Feedback Loop

您的使用习惯持续优化着搜索相关性。

### What We Track

| Signal | What It Captures |
| --- | --- |
| **Appearances** | 记忆在结果中出现的频率 |
| **Clicks** | 当你打开一条记忆查看详情时 |
| **Dwell time** | 你花了多长时间阅读 |

### 它如何提升搜索效果

- 高点击率表明该记忆确实实用
- 停留时间长表明内容价值高
- 频繁出现却无点击可能意味着相关性正在下降

你无需刻意为之，像平常一样使用 Nowledge Mem 即可。

## 图驱动发现

知识图谱通过关联实现探索。

### 记忆如何相连

每个记忆可关联至：

- **实体** ：提及的人物、概念、技术、地点
- **其他记忆** ：通过共享实体或关联关系
- **社群** ：图分析检测到主题集群

### 通过连接进行搜索

**实体关联** ：即使标签不同，也能通过 PostgreSQL 或索引等共享实体，找到关于"数据库优化"的记忆片段。

**社群关联** ：当搜索"认证"时，系统可能从你的"安全实践"社群中调取相关记忆片段。

**图谱扩展** ：从单个记忆节点出发，探索关联知识网络。

## Search Modes

所有界面均提供两种模式：

### Fast Mode

- 典型响应时间低于100毫秒
- 直接语义与关键词匹配
- 无需语言模型分析的实体与社群搜索
- 最适合快速查阅

### Deep Mode

- 完整语言模型分析
- **时间意图检测** （例如：“近期工作；过去十年的社会事件”）
- 提升召回率的查询扩展
- 上下文感知策略权重
- 更适合探索性搜索

两种模式均适用于主搜索、全局启动器和 API。

## Result Transparency

Nowledge Mem 清晰展示每条结果为何获得相应排名。

### 搜索查询详情

每次搜索后，您都可以查看查询被如何解析的详细分析

- 采用了哪些搜索策略
- 时间意图检测结果（深度模式）
- 查询扩展与实体提取

### Score Breakdown

将鼠标悬停在任何结果的分数上，即可查看其计算方式的详细分解：

- **语义匹配度** ：内容与查询的契合程度
- **衰减分数** ：基于时效性和更新频率的新鲜度评估
- **时间加权提升** ：事件时效性关联（如适用）
- **图信号** ：实体与社群的连接关系
