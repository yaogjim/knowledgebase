补充案例 一个人扛海外运营，跨时区 24 小时响应

你不是在做运营，你是在当一个跨时区的人肉路由器——凌晨 3 点欧洲客户发的邮件要等你早上 9 点起来才能转，而他已经在等了 6 小时。你的瓶颈不是能力，是你的生物钟。

你现在怎么处理的

客户消息这条线：早上起来打开 Gmail 和 Slack，翻过夜消息，判断优先级，逐条写回复。量大的时候光这一步就 1-2 小时。70% 的问题都是重复的 FAQ，但你得一条条手动答。

社媒数据这条线：手动打开 Twitter/Instagram 后台，把数据誊到表格里。最无聊的活，但不做不知道有没有爆款。

日报这条线：回忆今天干了啥，翻聊天记录，整理成 Markdown，发到国内群。每天下午花 40 分钟写一份没人细看的日报。

三条线全卡在你一个人身上，而且都跨时区。

Agent 介入之后

Claude Code 跑在你的 Mac 上，配合 launchd 每 15 分钟自动醒来检查一次，24 小时不间断。你睡觉时，它替你值夜班。

工具三件套：

gws（Google Workspace CLI）——读写 Gmail，起草和发送邮件 agent-slack——读写 Slack 消息，自动回复或存草稿 bb-browser——操作 Twitter/Instagram 后台，截图拿数据 凌晨 2 点，一个美国客户在 Slack 问 API 文档在哪。15 分钟后 Agent 醒来，识别出这是 FAQ，直接回了文档链接加引导语，同时推了一条轻量级 Bark 通知告诉你"已自动回复"。你睡着了，什么都没发生。

凌晨 4 点，欧洲客户发邮件投诉计费问题，等了 3 天没人回。Agent 读到邮件，判断「涉及钱 = 不能自动回」，做了两件事：给你发 timeSensitive 级别的 Bark 推送，同时在 Gmail 里起草好一封安抚邮件等你确认。

你早上 8 点还没起床，手机通知已经整理好了：6 条已自动回复，1 条计费投诉待你处理，社媒数据昨晚已跑完。你打开草稿，改了一个措辞，点发送，30 秒搞定。

下午 3 点，日报自动发到国内群，比你手写的还清楚。

怎么搭

\# 安装工具 npm install -g @googleworkspace/cli gws auth setup # OAuth 引导 npm install -g agent-slack

安装工具 npm 安装 -g @googleworkspace/cli gws 认证设置 # OAuth 引导 npm 安装 -g agent-slack

\# 配置 Slack export SLACK\_BOT\_TOKEN="xoxb-..." 然后在项目目录创建 CLAUDE.md，告诉 Agent 三件事： 哪些问题可以自动回（FAQ 列表） 哪些必须转给我（涉及钱、投诉、合作）

社媒数据怎么收集、日报用什么格式发到哪 最后设 launchd 定时任务，每 15 分钟跑一次。Agent 就这样 24 小时跑起来了。 你今天真正用脑子的时间：30 分钟。

剩下的时间，去想下个月的推广策略怎么调。这才是运营的活。
