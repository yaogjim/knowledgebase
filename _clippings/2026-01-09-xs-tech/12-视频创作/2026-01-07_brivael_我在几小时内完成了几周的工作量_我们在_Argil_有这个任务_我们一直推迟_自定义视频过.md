# 我在几小时内完成了几周的工作量 😮 我们在 Argil 有这个任务 我们一直推迟 - 自定义视频过

**Brivael** @brivael [2026-01-06](https://x.com/brivael/status/2008673658374385938)

我在几小时内完成了几周的工作量 😮 我们在 Argil 有这个任务 我们一直推迟 - 自定义视频过渡效果

像滑入这样的基础效果很简单，但任何风格化的效果都需要 OpenGL 和着色器，所以需要游戏开发技能，很难找到合适的人且耗时

我们的 Rust 混合引擎也不兼容，需要一个 C 插件来处理

我们妥协了，我请了个自由职业者，每天 800 欧元做最基本的工作（不涉及 OpenGL）

这个周末我决定用 Claude 来解决：给它所有 GStreamer/OpenGL/gl-transition 文档，把我们的代码库完整上下文都给它

它：- 构建了 C 插件，全面测试通过

\- 集成插件并添加原生帧复制逻辑

处理了着色器管理，让所有内容都在 GPU 上运行

整合了十几个扎实的过渡效果，现在我有了一个系统，我可以给它一个带有过渡时间戳的视频，它会提取帧，分析每一帧/步骤，编写着色器，然后告诉我检查——这真的太疯狂了
