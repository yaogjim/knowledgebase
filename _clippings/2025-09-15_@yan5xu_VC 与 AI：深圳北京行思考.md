4/n 还有是一系列对于 agent 生态的反思。首先是通用 agent，通用 agent 大概率会被垂直 agent 从专业度吃掉专业领域，然后被消费电子（手机、手表、眼镜、耳机、录音笔）把持的入口 agent 吃掉高频场景。唯一的机会是做好 agents 编排，在垂类 agents 爆发后，直接站在黄页-搜索-推荐的终点，最后被收购。

**yan5xu** @yan5xu [2025-09-14](https://x.com/yan5xu/status/1967056579892834508)

5/n 垂类 agent，核心是占住生态位，苟到某家同行，跑通从产品到模型的端到端训练（大概率是基于开源模型的监督过程 RL），打败最强通用模型，证明私有数据对于模型能力的提升，届时垂类 agent 的估值模型就不是如今的样子。
