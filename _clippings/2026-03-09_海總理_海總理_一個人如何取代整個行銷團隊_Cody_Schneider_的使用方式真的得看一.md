**海總理**

# 一個人如何取代整個行銷團隊？

Cody Schneider 的使用方式真的得看一下，我覺得我今天除了摸索這件事之外，再來就是研究一下他用到的幾個服務，特別是 Apollo ，即便是 AI 時代可能都沒辦法取代的資料服務(?)

以前一個行銷人員一天能做的事是有限的。設計廣告素材、上傳到 Facebook、追蹤數據、分析哪些表現好、關掉表現差的、再做新的。這個循環可能要花一個禮拜。現在 Cody 用 Claude Code 搭配各種 API，30 分鐘就能跑完整個流程。

## 實際戰術拆解：他到底怎麼做到的

API First，所有的服務都透過 API 來執行。

他先建了資料夾，裡面放一個 .env 檔案，存所有工具的 API Key。這些工具各司其職，組成一條完整的行銷作戰鏈：

Phantom Buster：LinkedIn 自動化爬蟲工具。

它能自動擷取 LinkedIn 貼文的所有互動者（按讚、留言的人），抓取他們的個人檔案資訊，包括姓名、職稱、公司、甚至信箱。簡單說，它把「手動一個一個點進 LinkedIn 個人頁面抄資料」這件事完全自動化了

Apollo：B2B 銷售情報平台

擁有超過 2.6 億筆企業聯絡人資料庫。當 Phantom Buster 只抓到一個人的 LinkedIn 基本資料時，Apollo 能幫你「充實」（enrich）這些資料。比如你只有一個人的名字和公司，Apollo 能幫你補上他的職級、公司規模、產業別、甚至直屬的商務 Email。它就像一本超級商業名冊，把模糊的線索變成完整的潛在客戶檔案

Million Verifier：信箱驗證工具

在你發出冷開發信之前，先確認這些 Email 是真實存在、能正常收信的。這一步至關重要，因為如果你大量寄信到無效信箱，你的寄件信譽會被毀掉，之後寄出的信全部進垃圾郵件。它就像發信前的最後一道品管

Instantly：冷開發信發送平台

它最大的特色是可以連結無限個寄件信箱，自動輪流發送，還內建信箱「暖機」功能（模擬正常互動來建立信譽）。這解決了冷開發信最大的痛點：量大但不進垃圾郵件

Rephonic：Podcast 搜尋資料庫

收錄超過 300 萬個 Podcast 節目的資料，包括聽眾數量、受眾輪廓、主持人聯絡方式。它讓「找到適合上的 Podcast」從大海撈針變成精準搜尋

Perplexity API：AI 搜尋引擎的 API 版本

Cody 用它來自動搜尋 Reddit、社群媒體上目標客群的真實痛點和討論，作為廣告文案的素材來源

## 工作流

理解了每個工具的角色之後，再看他怎麼把這些串成工作流就清楚多了：

1️⃣ 工作流一：LinkedIn 自動回覆。

有人在 LinkedIn 貼文下留言想要某個資源，Agent 自動抓取留言者、逐一回覆並附上下載連結。完全在背景自動完成。

2️⃣工作流二：批次廣告生成。

用 Perplexity API 去 Reddit 爬取目標客群的痛點（比如「資料分析師抱怨無法整合多個數據來源」），然後根據這些真實痛點批量生成上百個廣告文案變體，用 React 組件渲染成 1080x1080 的圖片素材。

3️⃣工作流三：Podcast 冷開發。

1.  用 Rephonic 搜尋行銷類 Podcast 主持人的聯絡信箱
2.  經過 Million Verifier 驗證信箱有效
3.  自動送進 Instantly 發送冷開發信邀約上節目。

整條流程從「找到目標」到「信寄出去」全部自動化。

4️⃣工作流四：LinkedIn 互動者轉換。

團隊任何人在 Slack 的指定頻道丟進一個 LinkedIn 貼文連結，Agent 就會啟動：

1.  Phantom Buster 抓取所有互動者的 LinkedIn 資料
2.  Apollo 充實完整的商務聯絡資訊
3.  Million Verifier 驗證信箱
4.  自動加入 Instantly 的冷開發信行銷活動。

從「某人在 LinkedIn 按了讚」到「收到一封個人化的冷開發信」，中間完全不需要人工介入。

每一個工作流都在背景獨立運作。他就像一個指揮官，在不同視窗之間切換，確認每個 Agent 有在正確的軌道上，然後繼續啟動下一個。

## 他的廣告訊息策略

Cody 是先用純程式碼（React 元件）快速生成大量「醜但精準」的廣告變體，測試哪個訊息角度最能打動人。找到贏家之後，再投入資源做精美版本。

這背後是一個很重要的行銷思維：

1.  用最低成本測試最多變體，找到有效的訊息角度
2.  確認贏家後，再投入資源做精緻化

一個廣告變體的生成成本大概就是一千個 token，幾乎等於零。所以他可以一次生成一千個變體，全部丟上 Facebook 測試，讓數據告訴他答案。

這比「花兩天做三個精美廣告然後祈禱」的傳統做法高效太多了。
