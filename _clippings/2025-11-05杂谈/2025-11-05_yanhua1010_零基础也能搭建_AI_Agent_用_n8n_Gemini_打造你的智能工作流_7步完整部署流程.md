**Yanhua 彦华** @yanhua1010 2025-11-03

零基础也能搭建 AI Agent！用 n8n + Gemini 打造你的智能工作流

7步完整部署流程：

1\. 安装 gcloud CLI 并登录

2\. 创建 Google Cloud 项目，启用必要 API

3\. 配置 PostgreSQL 数据库和密钥

4\. 设置服务账号权限

5\. 一键部署 n8n 到 Cloud Run

6\. 添加 Gemini API Key

7\. 创建 Workflow，配置 AI Agent 节点

几个实用应用场景：

• 智能客服机器人 - 7x24小时自动应答

• 邮件助手 - 自动分类/回复/安排会议

• 内容生成器 - 抓取信息生成社媒内容/短视频

• 品牌监控 - 接入 Reddit API 追踪趋势和舆情异常
