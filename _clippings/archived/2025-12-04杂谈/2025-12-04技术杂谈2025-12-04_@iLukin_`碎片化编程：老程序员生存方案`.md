AI 碎片化编程，是我这两年反复打磨出来的一套「老程序员生存方案」。

当程序员老了，有了孩子，你会发现：

人生被各种「一两个小时的小空档」切碎了。

比如：

送娃上兴趣班 → 等 90 分钟 → 接回家。

如果你没有一套碎片化编程方案，这段时间就只剩下刷短视频、发呆、瞎闲逛——纯纯浪费生命。

但如果把设备、工具和工作流都配好，这 90 分钟，就是你悄悄把产品往前推一小步的黄金时间。

01\. 核心理念

AI 写代码对「屏幕尺寸」的要求没那么高。

你只需要两件事：

•能看清它的输出

•能顺畅地和它对话、改代码、跑测试

剩下的算力和重活，全都在远程机器上干。

所以，Pad + 远程 + AI，其实已经够你完成 80% 的开发工作。

02\. 硬件怎么选？

iOS 系：

•iPad mini / iPad Air + 键盘

Android 系：

•8 寸以上 Pad（小米 / 华为 / 联想 / 三星都行）+ 键盘

一定要有键盘。

只靠触屏写代码，会把你逼疯，然后你就会回去刷视频😄

03\. 软件怎么配？

iOS：

•远程桌面：Screens / RustDesk

•SSH & 终端：ServerCat + mosh + tmux

•Diff 浏览：ccanywhere（把 diff 发布成网页）

Android：

•远程桌面：RustDesk

•SSH：JuiceSSH + mosh + tmux

•Diff 浏览：同样用 ccanywhere

底层逻辑很简单：

•后端任务 → SSH + tmux + AI

•前端 / 移动 UI 调试 → 远程桌面 + 浏览器 / 模拟器

04\. 后端开发：手机都够用

如果你是后端开发，其实连 Pad 都不是必需品。

•家里一台 Mac / Linux 服务器，或者一台 VPS

•手机上装个 SSH 客户端 + mosh + tmux

•代码用 AI 写，自己做判断、跑测试、看日志

只要网络还行，坐在培训班外面的塑料椅子上，你照样能改一个接口、查一个 bug、写一段脚本。

05\. 前端 / 移动开发：为什么要用远程桌面？

前端、移动开发还有一件事：看 UI 效果。

•浏览器预览

•App 模拟器

•真机调试

这些在本地 Pad 上跑都很痛苦，但在家里的主力机上跑就没压力了。

所以我的做法是：

•家里 MacBook Pro 当「编译 / 预览 / 模拟器」主机

•外出用 Pad，通过 VNC/Screens/RustDesk 回家里远程

•我这边只负责输入指令和看画面，所有编译发热、风扇狂转，都留给家里的电脑去承受

对 Pad 来说，这就跟「一直在看视频」差不多，电量非常耐用。

06\. 为什么不用一台 13 寸 MacBook Air？

很多人会说：

“搞这么复杂，不如直接背个 13 寸 MacBook Air。”

问题有三：

1.体积：13 寸背久了真的不算小，特别是带娃、旅居、通勤的时候。

2.续航：移动开发 / 大项目编译非常耗电，3～5 小时就开始找插座。

3.心态：一旦你背了一台「正经电脑」，你会潜意识觉得「必须找个像样的地方坐下来」，反而不容易进入碎片化工作模式。

Pad + 键盘 + 远程，让你更容易接受「随时随地写一点」这个状态。

07\. mosh + tmux：弱网环境下的解药

为什么我强烈推荐 mosh + tmux？

•mosh：弱网环境下输入极其丝滑，哪怕信号不稳定，也不会动不动断开。

•tmux：即使断网、App 被杀掉，你的开发会话还在，重新连上就继续干，不用重新打开 AI、重新切目录。

简单说：

它俩就是「弱网 + 碎片时间」开发的底层保障。

08\. 为什么要用 ccanywhere 看 diff？

在小屏设备上看 git diff，是一种折磨。

ccanywhere 的思路是：

•在家里机器上，把当前仓库的 diff 渲染成网页

•用你设置的通知渠道（钉钉 / 企业微信 / Telegram 等）发你一个链接

•你在 Pad / 手机上点开，就能舒舒服服地在浏览器里看 diff

这对「用 AI 改代码」特别重要：

•你可以清楚看到 AI 改了什么

•出问题时可以快速回滚 / 修补

•不用在终端里来回翻滚 diff

09\. 前端工程师额外的杀器：Playwright + AI Agent

前端工程师还可以更进一步：

•用 AI 帮你写 E2E 的 Playwright 测试

•再让 AI Agent 调用 Playwright 跑 UI 测试

你在外面用 Pad 写代码，回家里机器安静地跑测试，出报告再推给你。

这套东西组合起来，就是一个「远程 CI + 本地大脑 + AI 搓代码」的轻量级生产线。

10\. 为什么我要折腾这套碎片化编程？

对一个痴迷于创造产品的人来说，「任何时候都能创造」这件事太重要了。

•等孩子下课，不是浪费时间，而是产品往前推进了一点点

•出差 / 旅居，不是「停工」，而是换了个地方写代码

•你不用再依赖一整天的整块时间，而是学会把一整天拆成若干个高价值小段

想做独立开发者，想做一人公司，想做一个相对自由的人——

在谈理想之前，先把你的「刀」磨好：

•选好设备

•配好远程环境

•把 mosh / tmux / VNC / ccanywhere / AI 工具都调顺

•让你的「碎片时间」，真正变成「作品的一部分」

工欲善其事，必先利其器。

新时代的「器」，不只是电脑，还有：远程、AI、工作流，以及你愿不愿意在一小时的小空档里，打开终端，敲下第一行命令。
