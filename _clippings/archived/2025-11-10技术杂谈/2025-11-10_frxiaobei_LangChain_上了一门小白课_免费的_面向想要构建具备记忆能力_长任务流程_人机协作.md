# LangChain 上了一门小白课，免费的。 面向想要构建具备记忆能力 + 长任务流程 + 人机协作

**凡人小北** @frxiaobei 2025-10-27

LangChain 上了一门小白课，免费的。

面向想要构建具备记忆能力 + 长任务流程 + 人机协作点 的 AI agent 的开发者，语言是 Python 与 TypeScript。

没玩过的可以系统学习下，老用户啃文档就好。

看完动手码几个复杂的 Agent 问题不大。

划重点：

1\. 如何用 LangGraph 构建一个 agent 工作流

引入流程图式的 agent 编排模型，可以显式定义每一步该执行什么逻辑，什么条件下转移到下一步。

2\. LangGraph 的三大构建块

State、Node 和 Edge， 学习流程里共享状态，条件跳转或多路径分支等等。

3\. 如何加入 Memory

原生支持的多种 Memory 策略。

4\. 如何融入 Human-in-the-loop 操作

指定某个节点的输出必须经过人工审核等步骤，再继续流程。
