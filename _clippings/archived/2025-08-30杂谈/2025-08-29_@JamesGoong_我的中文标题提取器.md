Claude Code 使用技巧 4/n

https://x.com/JamesGoong/status/1959162430094787048…

\---

请为我生成一个"http://PLAN.md"文档，这份文档必须是一个待办事项的清单。

每一个待办事项，都必须是完整的，可执行，可运行，可提交，相对独立。

这些待办任务的顺序，需要按照依赖和优先级的方式排列。

每一个待办事项，请按照单个任务不超过2小时自然时间来进行切分。

每一个待办事项，都包含一个简要明确的标题，以及可以直接用来复制粘贴到 Claude Code 里的提示词。

每一条提示词，如果可以的话，请遵循下面的要求：

\- 在开头明确 Claude Code 需要扮演的身份，例如“你是一位资深的设计师，”

\- 如果可以的话，请提供范例代码

\- 明确约束和风险，清晰的告诉 Claude Code 不要做什么

\- 输出请按结构化的方式输出

\- 为需要ultrathink模式的任务添加ultrathink关键词

注意，上述提示词的要求，只是建议，请只在适用且你能因此更好工作的情况下再进行采用。

并将这份清单保存到"Claude-Context"文件夹中。

ultrathink
