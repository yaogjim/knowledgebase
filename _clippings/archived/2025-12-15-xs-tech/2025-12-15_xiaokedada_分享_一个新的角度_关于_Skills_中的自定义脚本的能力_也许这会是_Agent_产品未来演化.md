# #分享 一个新的角度，关于 Skills 中的自定义脚本的能力，也许这会是 Agent 产品未来演化

**nazha** @xiaokedada 2025-10-23

#分享 一个新的角度，关于 Skills 中的自定义脚本的能力，也许这会是 Agent 产品未来演化的方向

Agent 自主性心智模型的演化，从 LLMs 兴起之初的演化：

\- 单一提示：将上下文一次性提交给 LLM

\- Tool Use：让 LLM 开始使用工具，模型针对使用工具的能力进行强化

\- 自动编写脚本：模型更进一步，自己主动编写脚本、执行脚本来完成任务

目前还没有单一产品达到只通过 Agent 自动编写脚本执行任务，过渡阶段有可能是 Tool Use + 自动编写脚本作为辅助。
