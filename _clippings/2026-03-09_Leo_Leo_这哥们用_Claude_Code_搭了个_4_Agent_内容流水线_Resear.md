# Leo 这哥们用 Claude Code 搭了个 4-Agent 内容流水线： Resear

**Leo**

这哥们用 Claude Code 搭了个 4-Agent 内容流水线： Research 拉推文存库 → Ideate 生成 hook 创意 → Write 按个人风格出稿 → Orchestrator 编排调度。 每个 Agent 有持久记忆，Writer 记住你过去的反馈， Researcher 记住你常研究的账号。 我在做类似的事，散装跑了半年。最大的体会：Write 是最容易的环节，Research 信噪比才是瓶颈 —— 100 条推文里真正能用的不到 5 条。过滤逻辑比生成逻辑重要得多。下一步就是串成自动 pipeline。😁
