# 最高效的 AI 智能体都构建于这些核心思想之上。这正是驱动 Claude Code 的力量源泉。它被

**elvis** @omarsar0 [2025-11-08](https://x.com/omarsar0/status/1987167737639325886)

最高效的 AI 智能体都构建于这些核心思想之上。这正是驱动 Claude Code 的力量源泉。它被称为 Claude 智能体 SDK 循环，这是一个用于构建各类 AI 智能体的框架（建议收藏）。该循环包含三个步骤：收集上下文：使用子智能体（尽可能并行化以提高任务效率），压缩/维护上下文，并利用智能体语义搜索为 AI 智能体检索相关上下文。混合搜索方法在智能体编程等领域表现尤为出色。执行行动：借助工具、预构建的 MCP 服务器、bash/脚本（技能模块已大幅简化此过程），并通过代码生成来执行操作并为 AI 智能体获取关键反馈/上下文。实践证明，通过代码执行和路由也能增强 MCP 及令牌使用效率，这与 LLM 路由提升 AI 智能体效率的原理如出一辙。验证输出：可定义规则来验证输出结果，启用视觉反馈（这在多模态问题中愈发重要），并考虑采用 LLM 作为评判者，基于模糊规则验证质量。某些问题需要视觉线索及其他输入形式才能取得理想效果。 不要让工作流程过于复杂（例如，当巧妙的脚本技能就能胜任时，不必动用计算机代理）。这是一个清晰、灵活且稳固的框架，适用于在各个领域构建和使用 AI 代理。
