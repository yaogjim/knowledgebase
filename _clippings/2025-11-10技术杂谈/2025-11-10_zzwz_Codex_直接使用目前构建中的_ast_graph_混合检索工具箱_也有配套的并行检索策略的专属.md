# Codex 直接使用目前构建中的 ast-graph 混合检索工具箱 (也有配套的并行检索策略的专属

**不鍊金丹不坐禪** @zzwz 2025-11-09

Codex 直接使用目前构建中的 ast-graph 混合检索工具箱 (也有配套的并行检索策略的专属 Code Search Agent as Tools 可以给任何 e.g. Claude/Codex 当成工具用)

> 2025-11-09
> 
> 正在构建测试一个低延迟混合代码检索 Agent + Tooling
> 
> 目标
> 
> 主要目标低延迟导航大型代码库的目标检索任务。次要目标保持高精确度：
> 
> • 任务延迟 Latency:：分层导航识别目标代码位置所需的时间。
> 
> • 精确度 Precision：正确识别位置的百分比。
> 
> • 召回率 Recall：所有正确位置中被识别出来的比例。
