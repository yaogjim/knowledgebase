# Leo 关于 x-reader，没想到反响这么热烈。我日常用最多的场景就是看到好内容，直接丢

**Leo**

关于 x-reader，没想到反响这么热烈。我日常用最多的场景就是看到好内容，直接丢给 Claude Code 帮我解读，给出下一步行动。 评论区很多人问能不能开源，搞好了。说实话有点紧张——这是我人生第一个开源项目，年前我连 Python 都不会写（现在也不会，都是 AI vibe coding 出来的）。 x-reader 本身做的事很简单：给它一个链接，不管来自哪个平台，它把内容抓回来，转成统一的 Markdown。之前展示的「扔链接 → 自动分析 → 行动清单」，那是 x-reader + Claude Code 协作的完整体验。 支持的平台：微信公众号、小红书、X、YouTube、B站、Telegram、RSS——扔链接就行，平台识别和反爬都自动处理。YouTube 能直接提取字幕，没字幕的视频自动走 Whisper 转写全文。配合 Claude Code Skill，B站视频、小宇宙、播客也能全文转录。输出可以直接存进 Obsidian。 设计上分了三层，按需组合： • 基础层（CLI）——pip install 完 x-reader <链接> 直接用 • AI 增强层（Skills）——视频/播客全文转写 + 结构化分析 • 工具层（MCP Server）——4 个接口，接到你自己的 AI 工作流里 整个项目从第一行代码到现在，全程 Claude 辅助完成。我不是程序员，但 AI 让 Builder 和 Coder 之间的墙越来越薄了。 第一次做这件事，大概率很多不完善。有问题直接提 issue，想交流也欢迎——我也在学 [http://github.com/runesleo/x-reader…](https://t.co/6o3VLlWGrY)
