# 小耳Jane｜Xiaoer 拆了一下 Google Lab 刚出这个 Pomelli 的思路

**小耳Jane｜Xiaoer**

拆了一下 Google Lab 刚出这个 Pomelli 的思路： 它做的事其实是三步： 1. 爬你的网站 → 提取配色/字体/视觉风格 2. 生成一个"品牌 DNA"向量 3. 所有输出都锚定在这个向量上 这个思路完全可以自己复现： → 用 Claude 分析网站截图，提取设计语言 → 写成 style guide prompt → 后续所有生成都带上这个 prompt 我用自己的艺术网站测了（录屏在下面 ![👇](https://abs-0.twimg.com/emoji/v2/svg/1f447.svg)） 确实能读懂我的艺术美学,还能灵活生成 不过更大的感触是—— 生图、视频越容易,出来的东西越千篇一律 真正的差异化不是你用了什么工具 而是你有没有一套自己的视觉语言 这才是 AI 替代不了的东西 你觉得品牌"DNA "包含哪些元素？ 怎么才能独特而不是千篇一律？ 需要请留言，我后面专门拆解 ![👇](https://abs-0.twimg.com/emoji/v2/svg/1f447.svg)
