# Shann³ 我构建了一个 4 代理系统，用于撰写 X 内容。 我给它一个主题。它在 X 上

**Shann³**

我构建了一个 4 代理系统，用于撰写 X 内容。 我给它一个主题。它在 X 上搜索相关推文，存储研究内容，以不同的吸引角度生成想法，用我的语气写草稿，并推送至 Typefully。 流程： > 研究：抓取推文并将它们存储在数据库中 构思：生成带有钩子公式和关键点的结构化想法 写作：运用语音风格指导 + 文案框架，匹配我的语气 编排：通过每个阶段路由请求 每个代理都有自己的记忆，该记忆会在会话间持续存在。撰写代理会记住我对过往草稿给出的反馈。调研代理会记住我喜欢研究的账号。 用 Claude Code 构建了整个系统。仅使用 Markdown 提示词、数据库和命令行工具。
