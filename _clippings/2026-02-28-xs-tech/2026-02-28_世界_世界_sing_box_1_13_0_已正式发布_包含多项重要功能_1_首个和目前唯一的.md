# 世界 sing-box 1.13.0 已正式发布，包含多项重要功能： 1. 首个和目前唯一的

**世界**

sing-box 1.13.0 已正式发布，包含多项重要功能： 1. 首个和目前唯一的真正的第三方 NaiveProxy 客户端，其是 TLS 代理抵抗流量监测的最优解。 2. 改进的 Linux TUN redirect 支持，可以通过 bypass rule action 将需要直连的流量绕过 sing-box。 3. 首个和目前唯一的支持 ICMP echo 代理和分流的内核
