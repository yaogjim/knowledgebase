**王赞** @wangzan101 2026-01-11

利用 skill，自动将文章同步到 X 的草稿箱中，彻底告别 X 编辑器繁琐的排版和图片上传。  
  
几经折腾，终于实现了@wshuyi 老师的 skill，现在本地写文章，然后只需要一句：  
  
把“./这篇需要发表的文章.md”发布到 X，然后 claudecode 就会哼哧干活，最后把文章上传上去。  
  
只需要一句话和两三个 Enter 键盘，然后我们就不用操作了，相较于以往自己慢慢上传排版文章，上传图片，这个效率高太多了。  
  
视频展示的是在终端输入命令然后 claude code 干活的整个流程，视频无加速。  
  
输入命令后，我们就可以去处理其他的事了，能过彻底把双手解放出来，这个 skill 绝对的效率神器。  
  
大家如果经常在本地写文章，然后发表到 X 的，推荐使用，非常方便快捷。  
  
如果各位感兴趣，后面我也考虑写一篇更加文章详细的介绍一下，王老师文章内容需要一定的基础，还是有点难度。  
  
此外，基于王老师的这个思路，那么是不是可以做一个 skill 自动将文章同步到全平台。  
  
公众号，知乎，CSDN，X，medium，豆瓣……  
  
应该可以实现，大家有兴趣可以交流一下，这应该是一个很不错的想法。
