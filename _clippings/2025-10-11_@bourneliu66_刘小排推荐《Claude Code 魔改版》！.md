Claude Code for VS Code 魔改版！强烈推荐大家使用！

\- 支持YOLO模式，彻底释放双手

\- 支持直接配置第三方模型，不需要打开反人类的配置文件

\- 不需要登录官方Claude Code账号

去VS Code 插件市场搜索 Claude Code YOLO 即可，或者通过这个链接安装 https://marketplace.visualstudio.com/items?itemName=yuanzhixiang.claude-code-yolo… 你会回来感谢我的！
