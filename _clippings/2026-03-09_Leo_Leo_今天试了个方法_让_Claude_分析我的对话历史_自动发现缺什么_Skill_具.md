# Leo 今天试了个方法：让 Claude 分析我的对话历史，自动发现缺什么 Skill。 具

**Leo**

今天试了个方法：让 Claude 分析我的对话历史，自动发现缺什么 Skill。 具体操作：把 30 个现有 skill 列表 + 最近两天的工作日志丢给它，问"哪些高频操作没有被 skill 覆盖？" 跑完给出 3 个 gap，全部当场建好： - 贴个地址就自动跑策略画像 - session 结束自动扫描今天有没有推文素材 - X 长文抓取自动选最省 token 的方式 关键发现：建 skill 不难，难的是"知道该建什么"。让 AI 审计 AI 的工作流，比自己拍脑袋靠谱。 还有个细节 — 建完之后我第一反应是"我会记得用吗？"所以全部改成自动触发，不靠手动输入命令。工具做出来没人用，等于没做。
