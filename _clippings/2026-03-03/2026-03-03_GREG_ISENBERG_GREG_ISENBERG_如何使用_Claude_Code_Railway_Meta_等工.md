# GREG ISENBERG 如何使用 Claude Code、Railway、Meta 等工

**GREG ISENBERG**

如何使用 Claude Code、Railway、Meta 等工具来快速组建全天候运营营销的数字员工团队 1. 创建一个文件夹。将包含你使用的所有 API 密钥（Facebook 广告、Instant、Phantom Buster、Perplexity、GA4、Slack、Notion）的环境文件放入其中。开始用 API 的思维方式思考（新的思维模式）。 2. 打开该文件夹内的 Claude 代码（或任何代理框架）。你的工作变成了描述工作流程。代理会编写软件。你只需润色输出。“中间工作”就此消失。 3. 选择一种工作流程。例如：批量生成 100 个基于真实痛点的广告变体 → 上传到 Facebook → 获取实时数据 → 停止投放效果不佳的广告 → 扩大投放效果最佳的广告。构思、创建、分析、优化……所有环节环环相扣。 4. 并行运行多个代理。例如，一个代理回复 LinkedIn 评论；一个代理抓取播客主持人的信息并发送陌生邮件；一个代理根据你的广告数据构建仪表盘。你就像一个代理管理员。在本集中，你将实时看到这一切，在新窗口中启动新的桌面/Claude 代码，真是太疯狂了。 5. 将可重复的工作流程部署到铁路或其他任何服务器。现在它们可以持续运行。定时任务每天检查性能。仪表盘自动更新。简报每天早上都会发送到您的收件箱。 6. 开始以复合循环的方式思考： 想法 → API 链 → 实时数据 → 自动优化 → 重新部署 → 重复 本集将带您了解完整的堆栈实时运行情况。
