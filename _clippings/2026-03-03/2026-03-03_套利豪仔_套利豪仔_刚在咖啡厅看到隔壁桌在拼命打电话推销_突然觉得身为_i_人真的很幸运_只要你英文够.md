# 套利豪仔 刚在咖啡厅看到隔壁桌在拼命打电话推销，突然觉得身为 i 人真的很幸运，只要你英文够

**套利豪仔**

刚在咖啡厅看到隔壁桌在拼命打电话推销，突然觉得身为 i 人真的很幸运，只要你英文够好，其实有一堆 Remote 兼职可以躺赚，完全不需要面对跟人社交的压力 我发现 i 人加上英文专业，其实就是天生的吸金组合，因为语言工作非常需要那种能静下心来独处的专注力。 首先呼吁各位，真的不要再去接那些奇怪群组里的低价笔译单了。想当 Remote interpreter 或 Translator，你要去国外的平台看，像是 Lionbridge、ProZ 或是TranslatorsCafe 才是对的地方。 朋友有阵子是被外网一个博主 Zeliha Akpinar 给推坑的，她本人是个超级卷王，主业是医生竟然还能兼职一堆副业，看了她的分享我才发现国外平台的薪资真的香很多。 如果是那种平常爱追剧、爱听八卦的，可以去试试 Subtitling 字幕翻译。 像 Rev 这种平台的薪资就比较合理，一分钟大概一美金。真的不要再去做那种一小时才几十块的兼职了，那是在浪费你的听力才华。虽然这行真的很考验细心度，但对 i 人来说，对屏幕敲敲打打比对人讲话轻松多了 还有一个很低调但很赚的叫「技术写作」。就是编写用户手册、产品说明书或是 API 文档。科技公司跟软体公司对这类人才需求超旺盛。你要是懂一点点编程或是结构化写作，直接就是拿米拿到手软。英文专业的底子在那边，写这些 Report 或 Review 根本是降维打击，不会的去搜一下入门教学很快就能上手。 如果文笔不错，我也很鼓励去接海外企业博客或网站的稿子。直接去 Upwork 或 Fiverr 接单，只要成交一个真的会爽到不吱声。海外很多企业其实很缺懂互联网思维的人帮忙写文章，这甚至能当成自媒体经营，做好了以后想去国外工作也算是一块敲门砖。 最后就是留学申请的文案润色。帮忙看 PS 或 CV 之类的，如果你有留学经验那竞争力直接拉满。建议大家找那种小型的代办机构或是自己接案，遵循「大机构钱少事多、小个体钱多事少」的原则。一对一的咨询费真的高很多，而且这种纯文字往来的沟通对 i 人来说简直是天堂 想要找 Web3 或远程工作的，后面我在整理一个合集给各位分享
