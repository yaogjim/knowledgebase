# 凡人小北 这篇文章提供了一个新思路： 当你真的需要多 Agent 协作时，怎么做才不会变成差

**凡人小北**

这篇文章提供了一个新思路： 当你真的需要多 Agent 协作时，怎么做才不会变成差生文具多？ 答案是就用文件系统。一个 Agent 写文件，其他 Agent 读。协作层就是磁盘上的 markdown。 作者用 8 个 Agent 跑了 40 天，同一个模型，产出质量天差地别。 一个核心洞察：多聊。模型不会自动变聪明，但它周围的文件会越来越丰富。 顺便说一下，我的 AI 采用了不同的方案：多 skills +多 subagent + swarm ccg，但是基础一样，全是文件，没有魔法。
