# 烁皓 Claude 订阅账户（ProMax）能合规用在 OpenClaw 上，不用走API

**烁皓**

Claude 订阅账户（Pro/Max）能合规用在 OpenClaw 上，不用走API也不单独在OpenClaw走auth。 方法超级简单（亲测有效，合法合规，没违反 Anthropic 规定）： - 先正常安装配置好 Claude Code（就是 Anthropic 官方那个终端工具） - 打开你的 OpenClaw（小龙虾），直接对它说一句自然语言指令：接入 Claude Cli 龙虾会自动帮你完成接入，正常接入之后，再设置 anthropic/cli:claude 作为默认模型，就能把你的 Claude 订阅额度拉到 OpenClaw 里用。 同理，你也可以直接说：“接入 Gemini Cli” 或者其他支持的，同样丝滑接入。 赶紧试试这招式！用过的来评论区报个平安，没试过的速速行动～
