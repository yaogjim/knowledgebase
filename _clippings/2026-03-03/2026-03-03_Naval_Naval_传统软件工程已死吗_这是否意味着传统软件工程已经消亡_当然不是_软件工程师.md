# Naval 传统软件工程已死吗？“这是否意味着传统软件工程已经消亡？当然不是。软件工程师——

**Naval**

传统软件工程已死吗？“这是否意味着传统软件工程已经消亡？当然不是。软件工程师——即使是那些不一定负责调优或训练人工智能模型的工程师——如今也是全球最受重视的人群之一。当然，那些负责训练和调优模型的工程师更加受重视，因为他们构建了软件工程师使用的工具集。但软件工程师仍然拥有两大优势。首先，他们用代码思考，所以他们真正了解底层运行机制。而所有抽象都是有漏洞的。因此，当计算机为你编写程序时——比如使用 Claude Code 或其他类似的程序——它必然会出错，存在 bug，架构也并非最优。所以它不可能完全正确。而了解底层运行机制的人能够及时堵住这些漏洞。因此，如果你想构建一个架构良好的应用程序，如果你想能够明确地定义一个架构良好的应用程序，如果你想能够让它正常运行，那么软件工程师就至关重要。”要想获得最佳性能，如果你想让它发挥最大效用，如果你想及早发现漏洞，那么你需要具备软件工程背景。传统的软件工程师能够更好地使用这些工具。而且，软件工程中仍然存在许多人工智能程序目前无法解决的问题。最简单的理解方式是，这些问题超出了它们的数据分布范围。例如，如果它们需要进行二分排序或反转链表，它们已经见过无数这样的例子，因此它们在这方面非常擅长。 但当你开始跳出他们的领域——当你需要编写高性能代码，当你运行在新颖或全新的架构上，当你真正创造新事物或解决新问题时，你仍然需要亲力亲为地编写代码。至少在积累了足够多的此类示例，足以训练新的模型，或者这些模型能够在更高的抽象层次上进行充分推理并独立解决问题之前，都是如此……记住：市场对平庸的产品没有需求。平庸的应用程序——没人想要，至少在它没有填补某个已被更优秀的应用程序占据的空白领域之前是这样。更优秀的应用程序几乎会赢得百分之百的市场份额。或许会有一小部分用户会转向次优的应用程序，因为它在某些小众功能上做得比主流应用程序更好，或者价格更低，或者诸如此类。但总的来说，人们只想要最好的。所以坏消息是，排名第二或第三毫无意义——就像电影《拜金一族》（Glengarry Glen Ross）里亚历克·鲍德温那句经典台词：“第一名得一辆凯迪拉克 Eldorado，第二名得一套牛排刀，第三名就被炒鱿鱼。”在如今赢家通吃的市场里，这绝对是真理。这就是坏消息：如果你想赢，就必须在某个领域做到最好。然而，你能做到最好的领域是无穷无尽的。你总能找到一个完美契合你的细分市场，并成为这个领域的佼佼者。这让我想起了我以前发的一条推文：“成为你所在领域世界第一。不断重新定义你所做的事情，直到梦想成真。”我认为这句话在人工智能时代依然适用。“
