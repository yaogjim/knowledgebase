# Steven Lynn Agno 创始人 Ashpreet Bedi 发了一篇长文： Age

**Steven Lynn**

Agno 创始人 Ashpreet Bedi 发了一篇长文： Agent 工程 = 分布式系统工程。这些问题（持久化、隔离、容错、扩展）我们已经解决了几十年，只是 AI 行业还没把这些经验带过来。 他总结了 Agentic Software 的 6 个支柱： Durability — Agent 如果崩溃，不能从头重来，要能暂停/恢复/checkpoint Isolation — 多用户隔离，数据库/向量库/模型调用都要有用户边界 Governance — 分级权限：自动执行 → 需用户确认 → 需管理员审批 Persistence — 没有持久存储的 Agent 不会进步，每次对话都应让下次更好 Scale — 你继承了上游 API 的所有限制和延迟 Composability — Agent 即服务，可以被其他 Agent 调用
