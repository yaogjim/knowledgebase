# @LangChain 非常重视交付可靠的代理，而 Agent Builder 正是做到了这一点。只需

**Kevin Frank** @KevinBFrank 2026-01-13

@LangChain 非常重视交付可靠的代理，而 Agent Builder 正是做到了这一点。只需几分钟，你就可以创建一个符合你使用场景的代理，并且你实际上可以理解背后的工作原理。

在 Agent Builder 中，你可以看到：

• 代理：定义代理角色和指令的系统提示

• 工具箱：代理实际可以调用的工具

• 子代理：复杂任务如何被分解和委派

• 技能：可重复使用的能力保存到内存（这样你就不用每次都重新提示了）

并且它直接与 LangSmith 集成，以实现对你的智能体的可观测性和评估。

为了提高代理的采用率，我们需要人们了解底层的一切运作。Agent Builder 和 LangSmith 就能做到这一点。
