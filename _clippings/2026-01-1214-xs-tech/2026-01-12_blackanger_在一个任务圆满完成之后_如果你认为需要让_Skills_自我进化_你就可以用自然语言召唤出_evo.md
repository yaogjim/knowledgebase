# 在一个任务圆满完成之后，如果你认为需要让 Skills 自我进化 ，你就可以用自然语言召唤出 evo

**AlexZ** @blackanger 2026-01-11

在一个任务圆满完成之后，如果你认为需要让 Skills 自我进化 ，你就可以用自然语言召唤出 evolution skill 来沉淀在这次任务中新学到的 Skill 。

因为有 Claude code 自动热更新 skills 的特性，你就可以再同一个上下文中继续完成后面的任务，而不会犯同样的错误。

如果你想，你可以按 makepad-skills 里的贡献方法，把你的沉淀的 skills 贡献给上游。
