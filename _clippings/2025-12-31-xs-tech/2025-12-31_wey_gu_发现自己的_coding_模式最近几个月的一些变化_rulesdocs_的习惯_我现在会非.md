# 发现自己的 coding 模式最近几个月的一些变化。 - rulesdocs 的习惯 我现在会非

**Wey Gu 古思为** @wey\_gu [2025-12-29](https://x.com/wey_gu/status/2005590413084930216)

发现自己的 coding 模式最近几个月的一些变化。

\- rules/docs 的习惯

我现在会非常谨慎引入 rules/mcp tools，相反会在文件、类、代码上以更聚集性（locality）的方式把重要的结论、演进历史、设计决定嵌入或者存在同一级别。让 swe agent 按需能搜到、pick up 到。

\- fine-grained conversation

比较少维护很长的 conversation，但是会把一个 topic 的 session 改好名字，方便之后找到后续需要的情况去 append。

\- 同一个 repo 下，也常常并行开更多新的 session。

\- 我之前总是提及的 pair coding 明显变少了，这使得我即使是 UI tweak 的任务也少用 composer-1 了，全都是 opus 了。
