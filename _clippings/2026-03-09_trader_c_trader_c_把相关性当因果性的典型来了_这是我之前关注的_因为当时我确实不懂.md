# trader-c 把相关性当因果性的典型来了，这是我之前关注的（因为当时我确实不懂。。。）

**trader-c**

把相关性当因果性的典型来了，这是我之前关注的（因为当时我确实不懂。。。）

宏观市场这么看就完蛋了

说的是"宏观"，实际上是"盯盘找故事"，这就是为啥我之前看宏观感到没啥用，非常奇怪的原因

今晚发生了一个事件，然后去看各类资产的价格反应，发现价格走势跟预期的"剧本"对不上，于是说"看不懂了"。

这不是宏观分析，这是新闻解盘

如果宏观分析关注的是中长期的结构性力量和它们之间的传导机制，就没有那种奇怪，没啥用的感觉了。

比如美联储的货币政策周期处在什么位置，全球信用扩张还是收缩，美元的中期趋势是强还是弱，财政赤字的方向，全球央行的储备配置在怎么变化。

这些东西决定了资产价格运行的大方向和大环境。

在这个框架下，某一天晚上某个讲话导致的短期波动，根本就不是宏观层面需要解释的东西。

对比一下，图中说"10年30年长债被抛售，收益率上涨，意味着金融流动性再将资产变为现金"

这句话听起来像宏观分析，但实际上他只是在描述一个当天的现象，然后硬套了一个因果解释。

宏观视角应该关注长端利率上行的背后，是通胀预期在变、是期限溢价在扩大、是财政供给压力、还是外国央行在减持美债？

这些不同的驱动因素对应完全不同的市场含义，不是看到收益率涨了就下一个笼统的结论。

相同的过程，驱动因素不一样结果肯定不一样啊

你坐飞机去上海，从过程上说同一航班的人和你一样都是去上海，那结果能一样吗，你可能回家，别人可能去旅游，可能去看演唱会

把日内的多资产价格波动拼在一起，用地缘政治叙事去串联，然后管这个叫"宏观"。

这跟真正的宏观框架差得很远。

有用的宏观是先有框架和因果逻辑，再去看价格是否验证或者否定你的框架，而不是先看价格，再去找今天发生了什么新闻来解释。

即使搞一个美元指数从去年跌破100，市场进入弱美元共识，会释放流动性，这样虽然是解读简单的维度，但至少你在试图搭建一个有因果链条的框架，这个出发点比他那种方式要扎实得多。
