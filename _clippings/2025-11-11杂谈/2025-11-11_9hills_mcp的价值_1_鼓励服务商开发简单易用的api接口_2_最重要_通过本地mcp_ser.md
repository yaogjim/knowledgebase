# mcp的价值 1. 鼓励服务商开发简单易用的api接口。 2. （最重要）通过本地mcp ser

**九原客** @9hills 2025-11-09

mcp的价值

1\. 鼓励服务商开发简单易用的api接口。

2\. （最重要）通过本地mcp server 来封装已有接口，而不需要服务商配合。

> 2025-11-09
> 
> here's my gripes about mcp as an implementer
> 
> \- end users expect miracles from mcp and load in a bunch of them
> 
> \- most mcp servers are garbage, crash a lot, and the llm never bothers calling them
> 
> \- this whole "try sse and if it fails try streaming" is exactly why im so anti
> 
> 作为实施者，我对 MCP 的几点不满
> 
> \- 终端用户对 MCP 寄予厚望，并加载了大量此类工具
> 
> \- 多数 MCP 服务器都是垃圾，经常崩溃，而且 LLM 压根懒得调用它们
> 
> \- 这种“先尝试 SSE，如果失败再尝试流式传输”的做法，正是我如此反对的原因
