# AI 助手应该像你的首席助理一样：你告诉它你需要什么，它会想办法完成，并且会根据反馈持续改进。这就是

AI 助手应该像你的首席助理一样：你告诉它你需要什么，它会想办法完成，并且会根据反馈持续改进。这就是 Agent Builder 的核心理念。

首先，请用自己的话描述你的目标。Agent Builder 规划方法，引导你从最初的想法到一个已部署并准备好执行你的工作的代理。它制定详细的指令，选择所需的工具，在需要时甚至会调用子代理。

它与传统的工作流自动化不同。你无需映射每一个步骤、调整“如果-那么”式的分支逻辑，也不用操心依赖关系。只需像对待队友一样给它反馈，智能体便会通过记忆进行学习。它被完全从零开始构建为一个智能体，能够规划并迭代直至完成任务，或在执行敏感任务前请求权限。

### 用于实际工作的无代码代理

我们为所有被日常工作淹没的人打造了 Agent Builder。那些对您工作至关重要的调研、跟进、更新、日程安排和状态检查，却很快填满了您的日程。

团队已通过 Agent Builder 将数千个代理成功上线至生产环境。它尤其擅长处理跨多个应用、文档和工具的标签切换任务，例如：

- 日常简报：生成包含公司和利益相关者研究以及您 CRM 系统中相关客户信息的通话前简报。使用方式：“给我发送一份每日会议简报。”
- 市场与竞争对手研究：每日在 Slack 上为您的团队提供竞争对手产品发布、值得关注的社交媒体动态及团队应了解的行业趋势摘要。开始使用的指令是：“在 Slack 中给我发送每日竞争对手更新。”
- 项目跟踪：在 Notion 或 Google Docs 中，从产品需求文档（PRD）创建 Linear 任务，然后为关键里程碑创建日历事件。开始使用：“将我的 PRD 转换为 Linear 任务。”

### 让你的代理更上一层楼

多年来，我们的用户（主要是开发者）一直请求我们帮助其同事构建代理，且无需编写代码。Agent Builder 正是我们的解决方案。最初只是一个实用的生产力助手，却能演变为贵团队运作及软件交付方式的核心组成部分。随着您的需求增长，您可以借助 Agent Builder 的全部功能来扩展您的代理。

- 与团队共享代理：创建一个代理后，队友可通过共享工作空间克隆并调整它。
- 借助 MCP 增强代理能力：通过远程 MCP 服务器连接更多工具，包括自定义集成或您已使用的供应商提供的工具。
- 为工作选择合适的模型：自带模型以优化成本、延迟或性能。
- 随时随地使用代理：将代理嵌入到你的产品中，或者通过 API 调用它们，作为更大网络中的子代理。
