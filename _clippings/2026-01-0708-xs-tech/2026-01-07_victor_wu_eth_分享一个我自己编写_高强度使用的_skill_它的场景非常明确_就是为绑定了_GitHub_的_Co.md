# 分享一个我自己编写、高强度使用的 skill。它的场景非常明确，就是为绑定了 GitHub 的 Co

**victor-wu** @victor\_wu\_eth [2026-01-06](https://x.com/victor_wu_eth/status/2008554986264031604)

分享一个我自己编写、高强度使用的 skill。它的场景非常明确，就是为绑定了 GitHub 的 CodeX 账号的自动 review 功能做一个闭环：

1\. 改 bug

2\. 提交

3\. 等待 review

4\. 再改 bug

5\. 通过

通过这样一个步骤，形成一个完整的循环。

它的特点有两个：

1\. 全自动运行：我在中间加了一个5分钟的等待时间。如果你觉得不够，可以改成10分钟，或者让它在5分钟后再轮询5分钟

2\. 针对性优化：我针对 Codex 在 GitHub 上的 review 细节做了非常深入的用户优化。比如：

(a) 何时处于 review 状态

(b) 何时给出反馈

(c) 何时审核通过
