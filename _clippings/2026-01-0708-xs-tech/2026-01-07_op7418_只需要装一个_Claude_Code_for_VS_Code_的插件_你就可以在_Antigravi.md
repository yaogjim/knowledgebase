> 2026-01-03
> 
> VS Code 里用 Claude Code 如何开启自动操作模式，无需频繁手动确认？
> 
> 1、打开插件设置界面
> 
> 2、找到Claude Code: Initial Permission Mode 下拉选项框改为bypassPermissions
> 
> 3、新建对话框，确认是 Bypass permissions 即可，也可点击切换为其他模式，很方便
