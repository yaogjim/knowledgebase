# 凡人小北 Mac Mini 到了。 我今天干了件特别爽的事。

**凡人小北**

Mac Mini 到了。

我今天干了件特别爽的事。

把我整套 openclaw 基建，从云上整体搬回本地。

而且方式有点骚。

我没有用官方建议的打包整个 dot openclaw 目录，也没有用 git 还原 workspace。 说说骚操作：

按惯例龙虾应该有个家庭医生，所以我先在 Mac Mini 上先装了一个龙虾维修工。

然后我让云上的龙虾，自己做了一次完整复盘。从第一天开始装了什么，每个服务装在哪，依赖在哪等等等等（刚开始我就让他记录到单独文件夹了，所以你也可以让他去扫 session 下的记录）

全部给我列成一张清单 + 安装完成检查项。

等于让它自己写了一份自我说明书。

然后我把这份清单喂给本地的维修工。再把服务器 IP 和密码给它。 后面的事情基本就自动了。

它自己用 scp 一路把该拷的都拷下来，服务重建启动恢复。

过程中踩了一个坑：

Linux 的目录是 /root macOS 是 /Users/你的用户名

路径全错。

正常人会卡半天。

我的维修工直接自己定位问题，然后写了两行命令，把相关配置文件的所有路径批量替换。

再拉一次，直接起来。

整个过程非常快。 该还原的全还原，该重建的自动重建。

只需要让旧系统写清楚自己，让新系统照着做。

中间的人只负责监督。

说实话这种感觉真的有点爽。

一台 Mac Mini + 一个会修机器的龙虾。

比我当年抱着 Vim 抄配置强太多了。
