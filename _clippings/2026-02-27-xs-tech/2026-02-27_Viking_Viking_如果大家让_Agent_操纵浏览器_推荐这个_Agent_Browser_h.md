# Viking 如果大家让 Agent 操纵浏览器，推荐这个 Agent Browser [h

**Viking**

如果大家让 Agent 操纵浏览器，推荐这个 Agent Browser [https://agent-browser.dev](https://t.co/MJzZfAV8HB) 昨天给 TinyShip 写 e2e 用了它，感觉很好，关键是使用用 accessibility tree + ref 引用（

[@e1](/e1)

、

[@e2](/e2)

这种）代替完整 DOM / HTML / JSON 输出，一次 snapshot 通常只占 200–500 token，用语义 ref + 自然语言定位，AI 写脚本几乎不怕前端改结构。 我使用它的流程是让 Agent 用它跑一遍自然的真实流程，速度也很快，然后再根据这个真实流程再写Playwright 的 e2e，效率高很多。
