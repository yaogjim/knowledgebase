# 复制我的 AI 第二大脑配置（使用 Obsidian + Claude 代码，免费）

## 引言：无人解决的问题

你可能消耗很多。

书籍、文章、视频、播客。你做笔记。你保存重点内容。你甚至可能在某个地方有一个第二大脑，一个你曾经为之兴奋了三个星期，后来却变成了数字垃圾抽屉的文件夹系统。

一周后，即便你吸收了某些内容，也无法解释你学到了什么，哪怕以生命为代价。笔记还在，重点也都在。但你从未用过其中任何一点。

真相是这样的：问题不在于你消费得太少。问题在于你消费过多，却没有一个系统将其转化为有价值的成果。所以你最终得到的是一个整理得井井有条的坟墓。

然后 AI 来了，本应解决这个。

没有。

你打开 ChatGPT，解释你的上下文，得到一个不错的回答，然后关闭标签页。下一次会话：从零开始再次解释所有内容。AI 不认识你，也无法认识你。它无法访问你的笔记、项目或语音。因此，你给它通用上下文，得到的就是通用输出。你可能会花数周时间纠结于提示词，却仍然得到平庸的回答。

第二大脑方法——PARA、Zettelkasten、MOCs，它们都是有效的。但它们都需要数月的学习才能见效。大多数人花在构建系统上的时间比使用它的时间更多。

## 你需要的：两个工具

整个设置基于两个工具构建。就这些了。

Obsidian 是你的第二大脑所在之处。它是免费的，无需订阅，你的文件以纯 Markdown 格式存放在你的电脑上。你完全拥有自己的数据。与 Notion、Evernote 或任何专有工具不同，这里没有锁定风险。而且由于你的笔记是纯文本文件，AI 可以原生读取它们，无需 API 开销，也无需变通方法。

Claude Code 是驻留在您的保险库中的 AI 代理。Claude 应用程序可免费下载。要完全使用它，您需要订阅 Claude（约 20 欧元/月）。这就是设置的全部成本。

## 保险库里面有什么

保管库遵循 IPARAG 结构 ：六个文件夹，每个都有明确的用途。

- 收件箱 — 所有内容在你处理之前都会先到达这里。规则：定期处理至零。
- 项目 — 有时限的成果，带有完成节点。截止日期，完成标准。
- 领域 — 无期限的持续性责任。健康、事业、人际关系。
- 资源 — 参考资料、模板、指南、SOPs。
- 档案 — 已完成项目、过往内容、历史记录。
- Galaxy — 你的 Zettelkasten。每个概念一张笔记，扁平结构，永远成长。

前五个文件夹基于 PARA 方法：根据你打算对内容做什么来组织，而不是按主题组织。那个单一问题将每条笔记引导到正确的位置。

Galaxy 文件夹有所不同。它是你的知识库，通过维基链接永久关联，\*\*永远\*\*没有子文件夹。随着时间的推移，Galaxy 会成为你整个第二大脑中最有价值的部分，因为它会复利增长。你添加的每一条笔记都会与已有笔记关联，并创造新的价值。

该模板还包含一个完整的扁平标签系统，可按类型、状态和主题进行组织。这使得检索变得容易：你可以根据事物本身及其主题来查找，而不仅仅是根据存储位置。

如果你想深入了解完整的 IPARAG 系统以及 Zettelkasten 方法，我有一个视频涵盖了所有内容： 如何在 2026 年构建你的第二大脑

但关键点在于：Claude 已经接受过所有相关内容的训练。在系统正常工作前，你不需要数月的学习时间。AI 会为你处理方法论。

## 第二部分：连接 Claude 到你的保险库

步骤 1 — 下载 Claude 应用

前往 claude.ai/download 并安装桌面应用。打开后，找到 代码应用内的代码部分。这与标准聊天界面不同。它是 Claude 代码 所在的地方：一个可以直接访问你的文件系统的 AI 代理。

步骤 2 — 在 Claude 代码中打开你的安全库

在代码部分中，点击选择一个文件夹并将其指向你的 Obsidian 库文件夹。就这些。Claude Code 现在已连接到你的库，并有权限读取、写入和浏览你的文件。

步骤 3 — 启用 Obsidian CLI

在 Obsidian 中，进入设置并找到命令行界面选项。启用它。

这使 Claude 能够使用原生命令在你的知识库中导航，而不是逐个读取原始 Markdown 文件。它的 token 效率显著更高，并使 Claude 对系统有完整的结构理解。一个设置，激活一次后，Claude 在你的知识库中会变得明显更智能。

## 第 3 部分：配置你的 CLAUDE.md 文件

vault 模板的根目录下已包含一个 CLAUDE.md 文件。Claude 会在每次会话启动时自动读取该文件，且在其他任何操作之前。该文件已包含完整的 IPARAG 结构、路由规则、笔记格式和标签分类法——Claude 从第一天起就了解你的系统运作方式。

它尚未拥有的是你的个人情境：你是谁，你做什么，你正在构建什么，你当前的重点是什么。

填写的最佳方式是：打开 Claude Code 并让它对你进行面试。

输入类似以下内容："我想要个性化这个库根目录下的 CLAUDE.md 文件。开始一次对话——询问我你为了给我创建一个强大高效的 AI 第二大脑所需了解的一切。"

Claude 将会问你问题。你回答。它会自动写入并更新文件。

我的提示：使用一个语音听写工具，比如 Whisper Flow 来出声回答而不是打字。你给 Claude 提供十倍的上下文，用时只需四分之一。Whisper 可以在你电脑的任何文本框中使用，包括 Claude Code。

一旦 CLAUDE.md 填写完成，该上下文将在每次会话中自动加载。Claude 每次都会从第一个提示开始了解你的系统。

你第一次使用 Claude Code 时，它会了解你的文件夹结构。一周后，它会了解你的项目和当前重点。一个月后，它会成为你的个性化操作系统。它对你知识库的了解，比你在任何特定时刻能有意识记住的内容还要多。

你使用第二大脑越多，你的 AI 就变得越智能。自动。

## 五个入门用例

1\. 自动收件箱分类

将文件、笔记和高亮内容拖入你的收件箱。告诉 Claude：“帮我处理收件箱。”

Claude 读取每一项，将每个文件路由到正确的 IPARAG 文件夹，不确定时会询问。你的收件箱变为零。你什么都没做。

每当你想要更新文件夹结构或改变系统的工作方式时，你只需让 Claude 来更新。过去会占用你时间的维护工作，现在只需要一句话就能搞定了。

2\. 书本学习教练

你读完一本书，并且有高亮和文献笔记。告诉 Claude：“帮我梳理这本书的内容。”

Claude 阅读你的重点内容，询问哪些概念让你感到惊讶，哪些挑战了你已有的认知，并建议哪些想法值得转化为永久笔记。由你决定并记录。Claude 帮助你从噪声中提取信号，因为不是每个重点内容都值得转化为永久笔记。

你也可以让 Claude 在一周后对你进行关键概念的测验，以用于间隔重复。

而且由于 Claude 在你的知识库中，它能够发现这本书与你已有的关于其他主题的笔记之间的意外关联。这是你在聊天界面中难以轻易做到的事情。

3\. 连接查找

随着你的 Galaxy 不断扩大，你不再手动查看所有关联。当你有 300 条笔记时，你无法记住所有相互关联的内容。

告诉 Claude：“我的知识库中哪些笔记与这个概念相关？” Claude 会搜索整个知识库，呈现你遗忘的笔记，并建议创建新的链接。你的知识库保持活跃且互联，而非孤立。

4\. 写作伙伴

如果你想写新闻通讯或者视频脚本，告诉 Claude 主题。

Claude 将扫描你的整个知识库：过往内容用于语音参考、Galaxy 关于该概念的笔记，以及你已使用的结构。它呈现你已遗忘的相关想法，并建议一种与你现有写作方式一致的结构。它为你提供背景信息、连接点和支撑框架。然后你就可以写作了。

声音是你的。思考是你的。但你拥有一个 AI，它能将你的笔记提升为内容，而不取代你原本的思考。

一个了解你的个人信息的 AI 会生成听起来像你的输出，它由你真实的想法构建而成，而非通用训练数据。

5\. 日志模式分析

如果你在你的 vault 中定期记录，随着时间的推移，你可以让 Claude 分析你所有的记录。它会发现重复出现的主题、情绪模式、盲点，以及以不同名称出现的相同障碍。

你的第二大脑变成了一面镜子。一个人工智能驱动的日记，帮助你随着时间更好地了解自己。

## 这一切的一条规则

我不建议你让 AI 为你构建你的第二大脑。

如果 Claude 为你撰写所有永久笔记，那么你的知识星系将是 Claude 的思想，而非你的。如果 Claude 为你撰写所有内容，那么你的受众追随的是一个语言模型，而不是你。

将 AI 用作提升你思维的伙伴。让它呈现相关信息，提出你未曾发现的关联，并在你进行创作前梳理概念。但最终进行整合、决策和创作的是你。

这种区别就是一切。你的第二大脑应该增强你的智力，而不是取代它。
