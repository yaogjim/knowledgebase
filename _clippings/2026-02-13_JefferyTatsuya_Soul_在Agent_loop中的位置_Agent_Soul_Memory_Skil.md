# Soul 在Agent loop中的位置： Agent = Soul + Memory + Skil

**Jeffery Kaneda　金田達也** @JefferyTatsuya [2026-02-10](https://x.com/JefferyTatsuya/status/2021156569149329821)

Soul 在Agent loop中的位置：

Agent = Soul + Memory + Skill + Connector。

Memory 是"知道什么"，

Skill 是"能做什么"，

Soul 是"在乎什么、什么时候该主动"。

同样的 Memory 和 Skill，不同的 Soul 会产生完全不同的行为。
