# 中国那些富豪，是如何把钱“拿出去”的？

很多人以为，大额资金出境，无非是通过银行汇款，或者干脆带着现金过海关。

但现实中的跨境资金转移链条，远比想象中复杂。

在某些地下金融体系里，钱甚至不需要真正跨境流动，却能出现在海外账户；一笔资金经过几层结构运作之后，已经完全看不出最初的来源。

如果把整条路径拆解开来看，它通常会分成几个清晰的阶段：对敲、分层、加密路径、资产整合。

下面，我们一步一步拆开这条完整链条。

## 第一步：钱不过境——地下钱庄的“对敲”

整条链条的起点，是地下钱庄的“对敲”结构。

假设有人想将境内的一笔大额资金转移到境外。他并不通过银行跨境汇款，而是在境内把钱打入地下钱庄指定的账户。

这个账户表面上可能是：

- 一家奶茶店
- 一家贸易公司
- 一家咨询公司

名义通常是货款、服务费、往来款。

与此同时，地下钱庄在境外的合伙人，从其控制的境外账户中，向客户指定的海外账户支付等额外币。

这时会发生一个关键现象：

境内转账和境外转账在形式上毫无关联。 没有一分钱真正跨越国境线。 但资金控制权已经完成转移。

地下钱庄内部通过账本进行对冲清算，完成跨境“对倒”。

在法律层面，地下钱庄行为已被认定为刑事犯罪，其问题核心在于规避金融与外汇监管。

## 第二步：分层——壳公司之间的循环转账

当资金出现在境外账户后，下一步并不是直接使用，而是“分层”。

分层的目的，是让资金与原始来源之间的联系越来越模糊。

常见结构是多司法辖区公司组合，例如：

- 在 香港 注册投资或咨询公司
- 在 新加坡 设立科技服务公司
- 在 英属维尔京群岛（BVI）设立控股公司

这几家公司之间签署一系列协议：

- 技术授权费
- 品牌使用费
- 咨询服务费
- 投资管理费

然后资金在这些公司之间来回流转。

每一笔转账都有合同、发票、银行记录。 单独看，像是正常商业往来。 合并看，本质是资金分层。

在国际反洗钱理论中，这一阶段被称为 Layering（分层），是洗钱三阶段模型的核心部分。该模型由 金融行动特别工作组（FATF）提出，成为全球监管标准。

## 第三步：加密资产路径

在多层公司之间流转之后，一部分资金会进入加密资产路径。

逻辑通常包括：

1.  公司账户购买稳定币（如USDT）
2.  将资产拆分至多个钱包地址
3.  增加链上交易复杂度
4.  再用于场外交易或资产购买

在这一阶段，资金不再停留在传统银行体系内，而是进入区块链网络。

区块链账本公开透明，但地址本身不直接对应真实身份。这种结构会增加追踪难度，但并不意味着无法追踪。

当前全球多个司法辖区已将虚拟资产服务商纳入反洗钱监管体系，交易所KYC制度逐步强化。

## 第四步：资产整合——资金落地

当资金经过多轮分层与结构转换后，最后一步是整合（Integration）。

整合的方式通常是将资金转化为实体资产，例如房地产。

部分案例中，资产落地地区包括：

- 迪拜
- 阿联酋

房产持有人往往不是个人，而是离岸公司。

进一步结构可能包括：

- 房产登记在离岸公司名下
- 公司股东为信托结构
- 信托受益人为最终控制人

从法律形式上看：

- 离岸公司合法
- 信托合法
- 房产投资合法

但若资金来源存在问题，整条链条就具备洗钱结构特征。

## 第五步：完整链条的结构模型

将上述步骤抽象化，可以看到一个标准模型：

第一阶段： 非法资金 → 地下钱庄对敲 → 跨境控制权转移

第二阶段： 多层壳公司 → 商业合同包装 → 资金循环流转

第三阶段： 加密资产转换 → 地址分散 → 链上复杂化

第四阶段： 离岸公司持有资产 → 信托隔离 → 实体资产落地

这对应国际反洗钱理论中的三阶段模型：

1.  Placement（投放）
2.  Layering（分层）
3.  Integration（整合）

整条链条的核心，不在某一个单点是否合法，而在于是否存在对资金来源的掩饰与隐匿。

当把这些环节串联起来，就形成了一条完整的跨境洗钱结构。

每个步骤单独拆开，都可能是常见的金融工具； 但在特定资金背景下，这些结构组合在一起，就构成了一条完整的资金转移与分层路径。

这就是整条链条的逻辑全貌。 当你读到这里的时候，他们已经开始使用新方法了。
