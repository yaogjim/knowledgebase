为什么要用这样一套，

扫码连接不是更简单吗？

个人喜好，

因为 claude code 更新太快了，快的时候几天一个版本。

不知道哪天更着更着，

第三方插件带不动了，

第三方自己还要去各种适配，哪天自己 bug 了，手机上不去着急。

安卓系统本身是 linux，

termux 也是老牌手机终端了。

ssh 更是行业基建。

tmux 大家都熟悉。

这样组合起来，

不是最方便的方案，却是配好之后很稳的，

基本保证都上得去。

维护也简单。

减少对于不可控的依赖。

> 2025-12-03
> 
> 安卓手机玩 claude code 长期稳定方案：
> 
> 手机用 termux 连上 远端服务器。
> 
> 再进入 docker 容器。
> 
> 再启动 tmux。
> 
> 最后启动 claude code。
> 
> 继续奏乐继续舞。
