# Acbox 在 AI Agent 时代，OpenClaw 展示了令人兴奋的可能性，但其稳定性

**Acbox**

在 AI Agent 时代，OpenClaw 展示了令人兴奋的可能性，但其稳定性、安全隔离、配置复杂度和 token 消耗问题，也让许多团队望而却步。 我们推出 Memoh：一个真正面向生产、可落地的容器化多成员 AI Agent 系统。 - 每个 Bot 运行在独立沙箱中，拥有完整文件系统、网络与命令执行能力，却严格隔离，杜绝系统级失控风险。 - Qdrant 向量 + BM25 关键词混合召回，LLM 自动事实抽取、记忆压缩与重建，确保长期上下文高效持久，而非简单堆叠 token。 - 支持角色权限（owner/admin/member）、跨平台身份统一、群聊用户识别与 per-user 记忆；Bot 可互生子代理、分工协作。 - 现代 Web Dashboard（Vue 3 + Tailwind），图形化配置 Bot、Channel、MCP 工具、技能开关；实时监控容器状态、token 消耗与聊天流。 - 一键 Docker Compose + 自动迁移，支持 cron 定时任务、心跳自检、多模型分配（OpenAI/Anthropic/Google 等），适合服务器/NAS/云环境长期运行。 - Telegram、Discord、飞书、Email、Web/CLI 统一消息格式，支持富媒体、流式回复与跨通道 inbox 上下文延续。 GitHub: [https://github.com/memohai/Memoh](https://github.com/memohai/Memoh) [#AIAgent](/hashtag/AIAgent?src=hashtag_click) [#开源](/hashtag/开源?src=hashtag_click) [#MultiAgent](/hashtag/MultiAgent?src=hashtag_click) [#EnterpriseAI](/hashtag/EnterpriseAI?src=hashtag_click) [#容器化](/hashtag/容器化?src=hashtag_click)
