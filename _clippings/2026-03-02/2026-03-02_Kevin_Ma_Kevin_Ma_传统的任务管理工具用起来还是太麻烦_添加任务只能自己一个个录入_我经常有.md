# Kevin Ma 传统的任务管理工具用起来还是太麻烦，添加任务只能自己一个个录入。 我经常有

**Kevin Ma**

传统的任务管理工具用起来还是太麻烦，添加任务只能自己一个个录入。 我经常有个场景：和内测用户聊完之后，聊天记录里混着用户故事、需求点和闲聊，得自己梳理一遍，再一条条录进去。 现在直接把聊天内容全部丢给 AI，让它帮我梳理，我确认一下，它就去 Todoist 创建任务。也可以让它创建到 GitHub Issues，看具体的任务类型。省了不少事。 唯一麻烦的是微信不支持导出选中的聊天记录，只能截图或者手动复制。
