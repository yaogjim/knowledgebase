# Leo 和 Karpathy 一样的体感：12 月确实是 AI 编程的分水岭。 之前 cod

**Leo**

和 Karpathy 一样的体感：12 月确实是 AI 编程的分水岭。 之前 coding agent 还是逐行补全。现在给一句话需求，它自己读代码库、写完、测试、部署到服务器。 今天下午两小时，Claude Code 加密了服务器上 71 个凭证，又从零写了个内容采集器 —— 从代码到定时任务，一次对话搞定。 但 Karpathy 说的"质变"，我觉得核心不只是速度。是它开始记住你了 — 记得你上周踩过什么坑、哪个参数不能改。编程从对工具下指令，变成了跟一个有记忆的搭档协作。

> It is hard to communicate how much programming has changed due to AI in the last 2 months: not gradually and over time in the "progress as usual" way, but specifically this last December. There are a number of asterisks but imo coding agents basically didn’t work before December
