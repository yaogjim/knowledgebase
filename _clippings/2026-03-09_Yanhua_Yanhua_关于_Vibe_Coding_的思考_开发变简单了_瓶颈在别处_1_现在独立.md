# Yanhua 关于 Vibe Coding 的思考：开发变简单了，瓶颈在别处 1. 现在独立

**Yanhua**

关于 Vibe Coding 的思考：开发变简单了，瓶颈在别处 1. 现在独立开发太幸福了 原型：v0, Bolt, Lovable, Stitch 代码：Claude Code, Codex, Antigravity 一个人就能干出小团队的活。 2. 但工具越强，越要问自己：什么才真正重要？ 答案：工程思维。 Vibe coding ≠ 乱写。AI 帮你写得快，不代表可以不管结构。屎山写出来，想加功能都不知道改哪，这才是灾难。 3. 我的做法：Agentic Engineering •改动前先 plan，生成改动计划 •改完让 AI 总结文档 •所有模块维护到 [http://claude.md](http://claude.md) 你是指挥官，AI 是执行者。架构和方向必须你把控。 4. 更扎心的事实：开发已经不是瓶颈了。 真正难的是： → 你的产品会不会被大模型直接替代？ → 怎么推广？怎么获客？ → SEO、流量、增长，这些才值得花时间 5. 一句话总结： AI 让「做出来」史无前例地容易，但「卖出去」的难度一点没降。 代码能力在贬值，产品嗅觉和营销能力在升值。 共勉。
