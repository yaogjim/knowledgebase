## BERT 仅是文本扩散的一步

![Text Diffusion](https://nathan.rs/images/roberta-diffusion.gif)

不久前，Google DeepMind 发布了 Gemini Diffusion——一个通过扩散过程生成文本的实验性语言模型。与逐词生成的传统 GPT 风格模型不同，Gemini Diffusion 通过逐步优化随机噪声来生成完整的文本块。

我阅读了《大型语言扩散模型》这篇论文，惊讶地发现离散语言扩散实际上只是掩码语言建模（MLM）的泛化形式，而这项技术我们从 2018 年就开始使用了。我的第一反应是：“能否微调一个类似 BERT 的模型来实现文本生成？”出于好奇，我决定快速尝试一个概念验证。

> 注：在我写完这篇文章后，偶然发现了 DiffusionBERT 这篇论文，它基本上做了同样的事情，但测试更为严谨！如果你对本文感兴趣，不妨去了解一下。

## 变形器的简史

---

2017 年提出的原始 Transformer 架构采用编码器-解码器结构。2018 年，研究人员发现该模型的编码器和解码器组件可以分离（随着 BERT 和 GPT 的出现），由此形成了两大模型家族：

1. **仅编码器模型（BERT 风格，双向）**

编码器模型采用掩码语言建模（MLM）作为训练目标：随机遮蔽每个输入中的部分标记，并训练编码器重建缺失的标记（填空）。模型一次性观察整个（部分遮蔽的）上下文，学习双向表征。这种架构在需要完整句子（或段落）表征的任务（如分类和检索）中表现卓越。

1. **仅解码器模型（GPT 风格，自回归）**

解码器模型采用下一词预测作为训练目标：在每个位置 $t$ ，根据 $t$ 之前的所有词元作为上下文，预测位置 $t + 1$ 的词元。仅使用左侧上下文来预测后续内容（单向性）。这种架构在需要逐词生成文本的任务中表现卓越，例如开放式生成、摘要和翻译。

最初，BERT 在分类等任务中得到了迅速应用，而 GPT 风格的模型直到后来才流行起来（因其初期能力有限）。最终，自回归（解码器）变换器的生成能力得到了极大提升。与编码器模型相比，“下一词预测”这一通用训练目标意味着应用场景的覆盖面要广阔得多。

## 离散语言扩散模型

---

扩散模型最初在图像生成领域广受欢迎。在图像生成中，扩散模型会逐步向图像添加高斯噪声（前向过程），然后训练神经网络进行迭代去噪（反向过程）。基于图像的连续扩散过程可概括为：

1. 前向过程：从一张干净的图像 x₀开始，在每个时间步逐步添加少量（通常为高斯）噪声，直至图像几乎完全变为噪声。
2. 逆向过程：训练一个模型（通常为 U-Net）来预测每个时间步的噪声，通过离散去噪步骤逐步恢复原始图像。

将这一理念应用于语言领域，意味着我们需要找到一种方法，先对文本添加噪声，再分阶段去除。最简便的方式便是采用基于掩码的噪声处理过程：

1. 前向（掩码）过程：
	- 在时间步 t = 0 时，你拥有一个完全无损坏的文本序列。
	- 在随后的每个时间步 t > 0 中，根据预定义的调度规则（例如将掩码比例从 0% 逐渐增加到 100%），随机将部分标记替换为特殊的 `<MASK>` 标记。
	- 到最终时间步 T 时，整个序列可能被完全掩码（所有标记均为 `<MASK>` ）。
2. 逆过程（去噪）：
	- 训练一个模型（通常是一个标准的 Transformer 编码器），用于在时间步 t 给定部分被遮蔽的序列时预测原始标记 ID。
	- 这类似于在不同掩码率下进行掩码语言建模：在早期时间步，仅有少量标记被掩盖（易于预测）；而在后期时间步，大量标记被掩盖（预测难度增加）。
	- 通过将高掩码率的预测逐步串联至零，你可以恢复（或生成）一个完整的序列。

在此离散文本扩散框架中，模型通过优化所有时间步的去噪损失之和来学习数据分布的似然边界，而非在固定掩码概率下执行单一掩码语言建模目标。

正如我们所见，BERT 的掩码语言建模目标与文本扩散的训练目标相同，但仅适用于部分掩码率。通过引入可变的掩码率（从 0 到 1）以及按计划序列的去噪步骤（受扩散理论启发），我们可以将 BERT 的掩码语言建模目标转化为完整的生成过程。

## RoBERTa Diffusion

---

2019 年，RoBERTa 问世。它本质上只是对原始 BERT 模型的优化，拥有更优的超参数、更大的数据训练规模以及更简化的训练目标（仅保留掩码语言建模，移除了下一句预测任务）。

这里我们使用 HuggingFace 的 `transformers` 和 `dataset` 库来引入原始 RoBERTa 权重、分词器以及 Trainer 类，以便在 WikiText 数据集上轻松微调模型。主要代码如下（完整代码在此处）如下所示：

```python
# Load and tokenize dataset and instantiate the model
dataset = load_dataset("wikitext", "wikitext-2-raw-v1")
tokenizer = RobertaTokenizerFast.from_pretrained("roberta-base")
model = RobertaForMaskedLM.from_pretrained("roberta-base")

# Create the training args and Trainer instance
training_args = TrainingArguments(
    output_dir="finetuned-roberta-diffusion",
    overwrite_output_dir=True,
    num_train_epochs=NUM_EPOCHS,
    per_device_train_batch_size=BATCH_SIZE,
    save_strategy="epoch",
    save_total_limit=1,
    logging_steps=200,
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized["train"],
    eval_dataset=tokenized["validation"],
    data_collator=diffusion_collator, # custom implementation
    tokenizer=tokenizer,
)

# Train & save
trainer.train()
trainer.save_model("finetuned-roberta-diffusion")
```

目前我们采用 10 个扩散步骤，因此每批次会从 `mask_probs` （1.0, 0.9, 0.9, …, 0.1）中随机抽取一个比例 $p$ ，并按该比例对标记进行掩码处理。定制的 `diffusion_collator` 函数（参见此处代码）会为每个批次从 `mask_probs` 中采样一个掩码概率 `p` ，并以 `p` 的概率将每个标记设置为 `<MASK>` 。

为了能够基于“提示”进行条件生成，我们目前从不遮蔽前 16 个标记。这意味着在训练过程中，每一步都将始终以前 16 个标记作为生成上下文。

`diffusion_collator` 的简化代码如下所示：

```python
def diffusion_collator(examples):
      batch = tokenizer.pad(examples, return_tensors="pt")

      # Randomly select masking probability for this batch
      mask_prob = random.choice([1.0, 0.9, 0.8, 0.7, 0.6, 0.5, 0.4, 0.3, 0.2, 0.1])

      # Never mask the first PREFIX_LEN tokens (preserved context)
      maskable_positions = batch.input_ids[:, PREFIX_LEN:]

      # Create random mask for the chosen probability
      mask = torch.rand(maskable_positions.shape) < mask_prob

      # Apply masking
      batch.input_ids[:, PREFIX_LEN:][mask] = tokenizer.mask_token_id
      batch.labels = batch.input_ids.clone()

      return batch
```

在推理过程中，我们从大小为 256 的张量输入开始（因为要生成 256 个标记的文本块）。前 16 个位置是对应提示词的标记 ID，后 240 个位置则全是 `<MASK>` 标记。我们按照去噪调度表逐步迭代，每一步都会生成预测结果并重新对序列进行掩码处理。具体流程如下：

```markdown
Step 0: [PREFIX] <mask> <mask> <mask> <mask> <mask> ...     (100% masked)
Step 1: [PREFIX] will <mask> over <mask> control ...        (90% masked)
Step 2: [PREFIX] will begin <mask> greater control ...      (80% masked)
...
Step 10: [PREFIX] will begin to assert greater control ...  (0% masked - DONE)
```

生成用的简化代码如下所示：

```python
# Generate text through iterative denoising
for step, mask_prob in enumerate(mask_probs):
    # Forward pass: predict masked tokens
    with torch.no_grad():
        outputs = model(input_ids=input_ids, attention_mask=attention_mask)
        predictions = outputs.logits  # shape: (1, MAX_LEN, vocab_size)

    # For each masked position, sample from top-k/top-p filtered distribution
    for pos in range(PREFIX_LEN, MAX_LEN):
        if input_ids[0, pos] == tokenizer.mask_token_id:
            logits = predictions[0, pos, :]
            # Apply top-k and top-p filtering
            filtered_logits = top_k_top_p_filtering(logits, top_k=TOP_K, top_p=TOP_P)
            probs = F.softmax(filtered_logits, dim=-1)
            # Sample token
            sampled_token = torch.multinomial(probs, 1)
            input_ids[0, pos] = sampled_token

    # Re-mask a portion of non-prefix tokens for next iteration
    if mask_prob > 0:
        mask_indices = torch.rand(MAX_LEN - PREFIX_LEN) < mask_prob
        input_ids[0, PREFIX_LEN:][mask_indices] = tokenizer.mask_token_id
```

## Conclusion

---

我们已观察到，像 RoBERTa 这类最初为填空任务设计的掩码语言模型，可通过将可变速率掩码解释为离散扩散过程，被重新用作完全生成式引擎。通过用 `<MASK>` 标记逐步破坏文本，并训练模型在不断增强的掩码强度下迭代去噪，我们有效地将标准 MLM 目标转化为分步生成流程。

即便不对架构进行改动，经过微调的 RoBERTa 只需对训练目标稍作调整，便能生成看似连贯的文本，这验证了 BERT 类模型本质上仅是针对单一掩码率训练的文本扩散模型的观点。
