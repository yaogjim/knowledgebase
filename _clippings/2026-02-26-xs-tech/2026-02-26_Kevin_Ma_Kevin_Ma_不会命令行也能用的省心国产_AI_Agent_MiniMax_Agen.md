# 不会命令行也能用的省心国产 AI Agent：MiniMax Agent 上手实测

总有朋友问我，有没有哪个像 Claude Cowork 一样的 AI Agent 产品是不懂技术的普通人也能用的？最好开箱即用，不用折腾 VPN，价格别太贵。

说实话之前不好回答。好用的太贵，灵活的又太复杂。最近 MiniMax Agent 更新了，我抽空试了一下，确实是个不错的选择。

整个过程就像装一个普通软件，没什么门槛。不用像 OpenClaw 那样折腾配置，也不用像 Claude Cowork 那样先搞定网络代理和海外支付。

而且 MiniMax Agent 的客户端支持还挺全，Windows 和 Mac 都支持，还有 iOS 和 Android 版，访问

[https://agent.minimaxi.com/](https://agent.minimaxi.com/)

可以下载。

打开之后的主界面很简洁，核心就是中间一个输入框，用来给 Agent 下达指令。右下角能看到用的是最新的 M2.5 模型，下面是一些快捷功能，比如定时任务、批量处理、做网页、调研报告等。

![Image](https://pbs.twimg.com/media/HB_3e5Xb0AAmCPC?format=jpg&name=medium)

简单说，它能跑起来主要靠三样东西：

1\. M2.5 模型：性能追平一线，价格只要十分之一

M2.5 是 MiniMax 自研的最新模型。在 SWE-Bench Verified 这个业界最认可的编程能力测试里，M2.5 拿了 80.2%，Claude Opus 是 80.8%，基本同一水平线。在 Multi-SWE-Bench 上甚至排第一。完成同等任务的速度也接近 Opus。

但价格只要十分之一到二十分之一。说白了，差不多的活儿，干得一样好，但便宜太多。普通用户不用算着额度省着用，放开跑就行。

2\. 桌面协同 (Desktop Cowork)：不只是聊天，能直接帮你干活

这是它和普通 AI 聊天工具最大的区别。它能直接在你电脑上操作——打开浏览器搜信息、读本地文件、整理文件夹、生成文档。你给它一个任务，它自己就在桌面上跑起来了，不是只在对话框里输出一段文字让你自己复制粘贴。

3\. 专家社区 (Experts)：现成的工作流，拿来就用

MiniMax Agent 有一个专家社区，里面是各种封装好的自动化工作流，比如做 PPT、处理 Excel、生成调研报告等。不用自己从零开始写指令，找到合适的直接挂上用就行。目前社区里已经有上万个这样的技能，覆盖办公、财务、编程等常见场景。

它甚至还内置了 OpenClaw 的 skill，能一键帮你部署和配置 OpenClaw，对想进阶折腾的用户也留了口子。

我模拟了三个办公室里最常见的场景， 实际跑一下看看。

场景一：自动汇总周报

我往文件夹里扔了 5 份会议纪要和 3 份项目文档，然后用大白话跟它说：

“每周五下午 4 点，读我桌面‘本周工作’文件夹里的所有文档，按【项目进展】、【问题风险】、【下周计划】的结构写份周报，存到‘周报’文件夹。”

能看到它先把文件夹里的文档逐个打开、阅读，然后自己归纳出哪些内容属于进展、哪些属于风险。两三分钟后就出来了一份 Word 文档。内容基本准确，各个文档的要点都抓出来了，自己再稍微润色一下就能用。最烦的汇总信息这步，它确实能代劳。

而且因为设了定时任务，之后每周五它会自动跑一遍，不用每次重新下指令。

场景二：一句话做 PPT

我又试了试让它做竞品分析 PPT， 这个任务更复杂一些。

“帮我做一份 A、B、C 三个产品的竞品分析 PPT，要包括功能、定价和用户评价的对比。”

下完指令后，能看到它自己打开浏览器去搜信息，在不同网页之间切来切去、阅读、整理。整个过程跑了十几分钟，最后生成了一份 12 页的 PPT。内容框架没问题，数据也基本靠谱，设计上偏模板风格。从 0 到 1 的信息收集和整理它都帮你搞定了，拿到手之后再花点时间美化一下排版就能用。

场景三：市场信息搜集

我还试了一个信息搜集类的任务。

“帮我搜一下过去一周，网上关于‘AI Agent’的最新讨论和核心观点，总结成一份报告。”

它很快就开始在网上搜索，能看到它在不同的科技媒体、论坛和社交平台之间来回跳，点进文章阅读，遇到有价值的信息就摘出来。最后给出的报告里，按主题分类总结了几个核心观点，还附上了来源链接，方便你回去看原文。对需要快速了解行业动态的人来说，挺实用的。

场景四：批量处理文件

最后试了一个日常小需求。我桌面上有一堆乱七八糟的文件，截图、文档、下载的 PDF 混在一起。

"帮我把桌面上的文件按类型整理一下，图片放到'图片'文件夹，文档放到'文档'文件夹，PDF 放到'PDF'文件夹。"

它直接在桌面上操作，自动创建文件夹、识别文件类型、逐个移过去，几十秒就搞定了。这种活儿说大不大，但自己手动整理确实烦。能看出桌面协同的价值，它不是只能写文字，是真的能帮你在电脑上干活的。

## 

总结：什么样的人适合用？

测试下来，MiniMax Agent 的定位挺清晰的，适合这么几类人。

不想折腾技术、追求开箱即用的职场人。 不用像 OpenClaw 那样搞复杂配置，下载就能用，基本没有学习成本。Claude Cowork 也能开箱即用，但 MiniMax Agent 没有网络和支付门槛，对国内用户更友好。

预算有限、在乎性价比的个人或小团队。Claude Cowork 好用但贵，高频使用账单会很可观。MiniMax Agent 的 M2.5 成本低，可以没什么压力地高频用。

Windows 用户。 很多开源项目对 Windows 支持都不太好，配置起来麻烦。MiniMax Agent 有原生 Windows 客户端，体验稳定。

所以对于不想折腾技术的朋友来说，MiniMax Agent 确实是个不错的选择。省心，便宜，够用。
