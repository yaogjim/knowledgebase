# Andrej Karpathy CLI 之所以如此令人兴奋，恰恰是因为它们是一种“传统”技术

**Andrej Karpathy**

CLI 之所以如此令人兴奋，恰恰是因为它们是一种“传统”技术，这意味着 AI 代理可以原生且轻松地使用它们，将它们组合起来，并通过整个终端工具包与它们进行交互。例如，您可以让 Claude/Codex 代理安装这个新的 Polymarket CLI，并要求它们创建任意的仪表盘、界面或逻辑。代理会为您完成这些操作。安装 Github CLI 后，您可以让它们浏览代码库，查看问题、PR、讨论，甚至代码本身。例如：Claude 在大约 3 分钟内构建了这个终端仪表盘，其中包含了交易量最高的 Polymarket 以及 24 小时的涨跌幅。您也可以将其开发成 Web 应用程序或其他任何您想要的功能。当您将其作为大型流程的模块使用时，功能会更加强大。如果您有任何产品或服务，请思考：代理能否访问和使用它们？您的传统文档（面向人类用户）是否至少可以导出为 Markdown 格式？ - 你是否已经为你的产品编写了技能说明？ - 您的产品/服务是否可以通过命令行界面 (CLI) 或管理控制台 (MCP) 使用？ ……现在是2026年。为经纪人打造。
