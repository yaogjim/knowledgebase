# 我把 Naval Ravikant 的思维系统做成了一个 Claude Code 技能

Naval 的东西改变了我对财富和决策的理解。

问题是：每次读他的框架，点头如捣蒜，觉得自己想通了——然后真遇到一个决策，还是靠本能。知识在那里，用不出来。

所以我做了 Naval-OS。一个 Claude Code 自定义技能，把 Naval 的完整决策框架变成一种持续运行的思维模式。

## 

Naval 解决的核心问题

大多数人在优化错误的事情。

优化收入而不是财富。优化忙碌而不是杠杆。优化短期确定性而不是非对称回报。

Naval 的框架用一个过滤器切穿所有这些：

> 这件事，离开了我，还能跑吗？

如果答案是否，你在出卖劳动力。不管时薪多高。

## 

Naval-OS 做什么

把五个框架变成一个实时决策过滤器：

财富公式： 财富 = 专有知识 × 杠杆 × 判断力 × 责任心

杠杆优先级（这个排序很重要）： 代码 > 媒体 > 资本 > 劳动力

大多数人的职业生涯停在这个堆栈的底部。出卖时间。劳动力杠杆有硬上限：你的工时。代码和媒体杠杆没有上限。创作一次，价值无限复利。

六步决策过滤器 — 每个重大决策都跑一遍：

1.  第一性原理 — 剥掉惯例，什么是真的？
 
2.  动机分析 — 所有人真正想要什么？
 
3.  非对称回报 — 上行是下行的 10 倍吗？
 
4.  专有知识检验 — 这件事能被外包或培训吗？能的话，继续找。
 
5.  杠杆识别 — 这件事离开我还能跑吗？
 
6.  十年测试 — 十年后我还想做这件事吗？
 

## 

实际怎么用

触发词：naval-os 或 first-principles decision（首要原则决策）。

Claude 切换到 Naval 模式。每条回复严格遵循这个结构：

重新定义问题 — 你真正在问的是什么，通常不是你以为的那个。

第一性原理分析 — 2-4 句。只留本质。

专有知识 + 杠杆路径 — 具体可执行，不是原则。

下一步行动 — 一个动作，今天就能做。

风格是刻意简洁的。短句。不废话。像 Naval 发推特一样。

## 

为什么比「读 Naval 的书」有用

读框架不会产生习惯。自动触发的技能会。

当我深陷一个项目决策，打开 Claude，Naval-OS 不需要我记得「要用 Naval 的方式思考」。它直接跑。框架在正确的时刻出现，不依赖我有没有主动调用。

这是知道一个清单和清单在对的时刻自动运行的区别。

## 

更深的一层

Naval 最被低估的想法不是关于钱的。是关于判断力的。

> 专有知识来自你真正的好奇心和热情。它无法被培训出来。

你不能外包你的品味。你不能外包你对什么值得构建的判断。但你可以建立系统，确保你的判断真正被应用——持续地，在决策时刻，而不只是在理论上。

Naval-OS 是这样一个系统。
