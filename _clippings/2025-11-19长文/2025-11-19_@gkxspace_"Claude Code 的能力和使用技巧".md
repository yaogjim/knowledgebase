Claude Code 出的 Skills 很多人还不知道是什么。

用一句话说：

Skills = 教 AI 学会一项“可复用的能力”，像插件一样装上就能用。

能替代掉一些传统工作流，而且能力更强。但是对模型能力要求比较高，进步空间也还有很大。

比如：让 Claude 学会

• 统一品牌风格写作

• 按公司规范输出内部沟通材料

• 测试一个 webapp

• 生成视觉稿 / 图像

• 处理 DOCX / PDF / PPTX / XLSX

…这些都可以做成一个 Skill。

Anthropic 已经开源了一些官方示例和模板👇

🔗 https://github.com/anthropics/skills…

包括：

✓ 真实可用的文档处理技能

✓ 品牌指南技能

✓ 设计与图像生成技能

✓ web 测试、MCP、 artifacts builder 等开发技能

✓ 还有可直接复制的模板（template-skill）
