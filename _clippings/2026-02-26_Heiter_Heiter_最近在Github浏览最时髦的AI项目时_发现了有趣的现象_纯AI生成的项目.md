# Heiter 最近在Github浏览最时髦的AI项目时, 发现了有趣的现象：纯AI生成的项目

**Heiter**

最近在Github浏览最时髦的AI项目时, 发现了有趣的现象：纯AI生成的项目, 虽然能运行, 但代码量是\[古法编程程序员\]的上百倍，却能在短期内轻松拿到几万star。大量issue没人处理，作者挑容易的修一下, 剩下的放任自流。

我突然意识到：AI Coding就是我们的智子。

\> 在《三体》系列中，智子是一种假设的质子大小的超级计算机，由外星文明部署，用于干扰人类粒子物理研究，从而有效锁死人类的科学进步。

过去程序员需要努力的练习怎么写优雅高效的代码，创建一个项目，做出有价值的工作，频繁的更新和修复bug，才能得到几千star。

现在完全AI Coding，你可以付出更少得到更多：更多Github star -> 更多HR关注 -> 更好的职业跳板 -> 更高的收入。

激励机制已经彻底崩坏。一个工程师花费许多时间贡献一个开源基础库，得到的认可和回报不成正比。另一个靠AI堆出几十万行臃肿代码的项目，通过营销就能成为超级明星。

建造地基不再有回报，经济价值上没有，情绪价值上也没有。

当然大家都会往这条路走。而这意味着更少真正思考、更少深度经验、更少真实成长。

但关键是：AI生成的代码根本不创造任何新东西。它只是调用几代程序员积累的技术遗产——基础库、框架、工具链。没有这些地基，AI一行能跑的代码都写不出来。 这些AI项目能跑，纯粹是因为站在巨人的肩膀上。

AI看起来什么都能搞定——Excel、网站、一切, 但如果 pandas/polars/numpy/react 这一类基础库库突然从世界上消失，AI还能正常工作吗？被AI编码训练出来的年轻程序员，未来还有多少人有意愿、并且有能力去维护和贡献这些基础库？

我们这辈子再也看不到另一个新的操作系统诞生了。不会有更多复杂、高性能、大规模协作的基础性项目出现。上限已经被锁死。

软件世界的下限还能靠上一代的程序员留下的技术遗产维持一段时间。但随着那批人退休，下一代既没受过足够的训练, 也没动力去接替，腐朽会加速。

软件世界的天花板已被锁死。
