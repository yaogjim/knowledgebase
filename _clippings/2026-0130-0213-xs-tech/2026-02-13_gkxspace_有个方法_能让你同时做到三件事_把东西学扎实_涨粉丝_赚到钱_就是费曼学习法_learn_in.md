# 有个方法，能让你同时做到三件事：把东西学扎实、涨粉丝、赚到钱。 就是费曼学习法 + learn in

**余温** @gkxspace [2026-02-10](https://x.com/gkxspace/status/2021360027437838534)

有个方法，能让你同时做到三件事：把东西学扎实、涨粉丝、赚到钱。

就是费曼学习法 + learn in public。

费曼学习法的意思是：学完一个东西，试着用最简单的话讲给别人听。能讲清楚，说明你真懂了。讲不清楚，说明还有漏洞。

learn in public 的意思是：把你的学习过程公开出来。写博客、发视频、做笔记分享，都算。

这两个东西组合起来，就形成了一个正循环：

学东西 → 输出内容 → 输出倒逼理解 → 理解深了内容质量就高 → 内容好就有人看 → 有人看就涨粉 → 粉丝多了就能变现

所以说，如果你不知道自己现在的方向，那就按这套方法执行三个月，或许三个月后你就清楚了。
