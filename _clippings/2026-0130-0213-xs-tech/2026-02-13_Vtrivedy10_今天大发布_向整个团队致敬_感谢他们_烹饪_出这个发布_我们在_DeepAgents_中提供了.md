# 今天大发布，向整个团队致敬，感谢他们‘烹饪’出这个发布 🍳 我们在 DeepAgents 中提供了

**Viv** @Vtrivedy10 2026-02-10

今天大发布，向整个团队致敬，感谢他们‘烹饪’出这个发布 🍳

我们在 DeepAgents 中提供了一个通用沙箱接口，以便您可以接入任何沙箱或……任何看起来像沙箱的计算资源。

我们的朋友提供了一些很好的例子 @modal，@daytonaio， 和 @RunloopAI

总结/压缩很困难，因为长上下文理解难度大。每个构建工具的人都在研究如何改进它。我们在本版本中已落地了一些改进，这些改进应该更稳定，并且我们正大量采用卸载+延迟搜索模式用于压缩。

长上下文是一个活跃的研究领域，我们会分享更多内容，包括哪些方法有效、哪些方法无效，不过现在你可以随意查看我们的方法！

原生的 Responses API 支持，快去试用 Codex 模型！

并且如果你想要一个 CLI 在几秒钟内使用编码代理进行操作：

uv 工具安装 --upgrade deepagents-cli

deepagents --模型 ....

快乐建筑 :)
