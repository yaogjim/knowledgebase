# 如何优雅上车 Claude 满血版，驱动 Claude Code 高效干活👇 1. 在 prox

**idoubi** @idoubicc 2026-01-24

如何优雅上车 Claude 满血版，驱动 Claude Code 高效干活👇

1\. 在 proxycheap 买一个 isp 类型的美国住宅 ip

2\. 在 Clash Verge 之类的代理客户端，配置住宅 ip，设置一个 rule，把 claude 的流量走美国住宅 ip 访问

3\. 无痕浏览器打开 claude 网页版，使用一个域名邮箱注册账号

4\. 如果需要验证手机号，在 hero-sms 买一个 ireland 的虚拟手机号，接收验证码

5\. 使用境外的信用卡（wise、ocbc 等），支付 claude，首选 pro，按需升级 max

6\. 在 claude code 、claude 桌面版通过网页授权直连 claude 订阅账号

7\. 在代理客户端查看连接，确保访问 claude 相关域名的网络请求都走了美国住宅 ip 节点

\------
