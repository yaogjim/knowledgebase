# Claude Skills 的本质其实很简单： 1. 把 Prompt 变成入口 把关键信息都塞到

**idan** @eddiearc6 [2025-12-02](https://x.com/eddiearc6/status/1995673927067337148)

Claude Skills 的本质其实很简单：

1\. 把 Prompt 变成入口

把关键信息都塞到开头，按层加载，不用一页纸读完才能知道 skill 干嘛。

2\. 脚本 > 多轮扯皮

该用代码就用代码，别指望 LLM 连续10次都不跑偏。

3\. 打包能力，而不是写文档

一套 SOP + prompt + 资源，一份发出去，别人直接用，不用解释。

说白了：

📦 Skill = 一键复用的能力包，不是看起来很美好的prompt / mcp。

能直接用、能稳定跑、能快速复用。

相信这个东西很快就会火起来了。
