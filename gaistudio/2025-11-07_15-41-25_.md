### **揭秘 Claude Skills：动态、可重用的 AI 工作流**

今天，我将深入探讨 Claude Skills，包括它们是什么，如何创建它们，以及对于产品、工程和设计领域的专业人士来说，有哪些实用的应用场景。

那么，究竟什么是 Claude Skills？根据 Anthropic 的定义，Claude Agent Skills 是一套“有组织的指令、脚本和资源集合”，AI 智能体（Agent）可以发现并动态加载这些资源，以便更好地执行特定任务。简单来说，它是一种将你的专业知识打包成 Claude 可组合能力的方式，将通用的 AI 智能体转化为能满足你特定需求的专业化智能体。为智能体构建一项技能，就像是为新用户编写一份入职指南。

Claude Skills 解决了一个对于任何 AI 用户都至关重要的问题：即可重用工作流。它允许你创建一套指令，可以根据对话的上下文“按需调用”。这与 Claude Projects 或 OpenAI 的自定义 GPTs 有着本质区别。后者更像是静态的上下文容器，一旦你设置好一个项目并上传了相关文件，在该项目中的所有对话都会“始终调用该上下文和指令”。它们不是动态的，你无法根据需要在不同的对话中按需调用某个项目的功能。

相比之下，通用型项目或 GPTs 通常提供的是“通用目的的上下文”，可以服务于多种任务，但缺乏针对“特定任务的指令”。而 Claude Skills 的优势在于，它让你能够定义高度具体的、面向任务的指令，从而将一个通用的聊天机器人转变为能够代表你执行复杂任务的专业助手。

### **Skill 的剖析：从自然语言到可执行任务**

我特别欣赏 Claude Skills 的一点是，它完全基于“自然语言”构建。我们已经见过太多基于复杂工作流构建的智能体，例如充斥着“如果这样，就那样”（if this, then that）逻辑或需要调用特定工具的流程。我个人作为一名 AI 构建者，更倾向于一种更自然的方式：既然这些大语言模型（LLMs）如此擅长自然语言，我们就应该能够用自然语言来定义它们的工作方式。

Claude Skills 的核心正是如此。它本质上就是一个包含一系列 Markdown 文件的目录结构。这个结构的核心是一个名为 `SKILL.md` 的文件，它就是你的主要指令集。这个文件以 YAML frontmatter 开头，其中包含了技能的元数据，如 `name`（名称）和 `description`（描述）。在启动时，智能体会预加载这些元数据，这被称为“渐进式披露”（progressive disclosure）的第一层，使得 Claude 可以在不加载全部内容的情况下，仅仅通过名称和描述就知道每个技能的存在及其用途。

当 Claude 根据对话判断某个技能是相关的时，它才会读取完整的 `SKILL.md` 文件内容并将其加载到上下文中。这种设计非常高效。

此外，Claude Skills 的另一个强大之处在于它能够捆绑额外的内容。你可以通过相对文件路径在主 `SKILL.md` 文件中引用其他文件。这些被引用的文件可以是更详细的指令、代码示例、模板、API 文档，甚至是可执行的 Python 脚本。这种捆绑额外内容的方式，让技能变得极其灵活和可扩展。

这种基于文件系统的模型使得渐进式披露成为可能。Claude 会像浏览一份带有目录、章节和详细附录的手册一样，按需加载信息。它不会在工作时将整个技能的全部内容都读入上下文窗口，这意味着可以被整合到一个技能中的内容量实际上是“无限的”，同时又不会消耗不必要的 token。

最后，Claude Skills 还可以包含可执行的代码。例如，一个处理 PDF 的技能可以附带一个预先编写好的 Python 脚本来分析 PDF 并提取表单字段。Claude 可以在不将脚本本身加载到上下文的情况下运行此脚本，只将脚本的输出（如“验证通过”或特定的错误信息）消耗为 token。这种方式比让 Claude 动态生成等效代码要高效得多，并且由于代码是确定性的，工作流程也因此变得一致和可重复。

总结一下，一个 Claude Skill 的核心是一个文件夹，里面有一个 `SKILL.md` 文件和任意数量的辅助文件或脚本。这听起来可能有点技术性，但其实非常直观。

### **实践演练：创建你的第一个 Claude Skill**

根据 Anthropic 的官方文档，Claude 内部似乎存在一个可以创建技能的“元技能”（meta-skill）。于是，我首先尝试在 claude.ai 的网页界面中通过对话来创建我的第一个技能。我输入了提示：“帮我创建技能”（Help me create skills）。Claude 的回应是一系列引导性问题，它想了解我需要创建什么类型的技能，例如是处理特定文件格式、重复某个工作流，还是执行像数据分析这样的领域特定任务。

为了进行测试，我告诉它我想创建一个“产品需求文档（PRD）生成”的技能。随后，Claude 开始进行一系列的操作，它先是阅读一个示例技能来理解结构，然后查看更详细的示例，接着创建目录结构，最后生成了主 `SKILL.md` 文件。这个过程显得相当繁琐，它生成了大量的辅助文件，包括 `LICENSE.md`（许可证文件）、`README.md`（说明文件）、`QUICK_REFERENCE.md`（快速参考指南）等等，总共创建了大约12个文件，而我实际上可能只需要5个。更糟糕的是，当我尝试下载这些文件时，系统报错了。这个体验说明，直接在网页聊天界面通过对话生成技能或许不是最高效的方式。

于是，我转向了另一种我个人更偏爱的方法：使用 Cursor，一个专为 AI 协作设计的代码编辑器。这个流程要快得多。我首先在本地创建了一个名为 `claude-skills` 的空文件夹，并在 Cursor 中打开它。接着，我开启了一个新的聊天窗口，输入了以下指令：“为我创建一个用于创建 Claude 技能的智能体/技能。这是相关文档：@https://docs.claude.ai/en/docs/agents-and-tools/agent-skills/overview”。我直接引用了官方文档的链接，让 AI 自行学习。

Cursor 中的 AI 智能体迅速响应，并制定了一个清晰的待办事项列表（To-do list），包括：
1.  创建包含 YAML frontmatter 和核心指令的主 `SKILL.md` 文件。
2.  创建示例技能文件以演示不同的模式和用例。
3.  为常见的技能类型创建模板文件。
4.  创建一份全面的最佳实践指南。
5.  创建一个验证脚本来检查技能的结构。

整个过程非常迅速，只花了几分钟。AI 在我的本地文件夹中创建了一个名为 `create-skill` 的子文件夹，里面包含了所有必要的文件，结构清晰，组织合理。

接下来，我利用这个刚刚创建好的“创建技能”的技能，来生成一个全新的、用于实际工作的技能。我在 Cursor 的终端中启动了 Claude Code，并输入了我的需求：“使用 create-skill 技能来创建一个用于将客户演示笔记转化为试用客户跟进邮件的技能”（use the create-skill skill to create a skill for turning changelog entries into a user-facing newsletter）。Claude 识别并调用了我本地的 `create-skill` 技能，然后开始执行任务。它迅速创建了一个新的文件夹 `demo-to-follow-up`，并在其中生成了一个全新的 `SKILL.md` 文件，其中包含了将演示笔记转化为个性化跟进邮件所需的所有指令和结构。

### **如何使用和部署 Claude Skills**

在本地创建好技能后，如何将其部署到 claude.ai 的网页应用或桌面应用中呢？过程非常简单。首先，在你的本地文件浏览器中找到包含技能文件的文件夹（例如 `demo-to-follow-up`），然后将其压缩成一个 `.zip` 文件。

有一点需要特别注意：在上传之前，你需要检查 `SKILL.md` 文件中的元数据。我在第一次尝试时遇到了一个错误，提示“Skill name in SKILL.md can only contain lowercase letters, numbers, and hyphens.”（SKILL.md中的技能名称只能包含小写字母、数字和连字符）。这是因为我的技能名称 “Demo to Follow-Up Email” 包含了大写字母和空格。我将其修改为 `demo-to-follow-up-email` 后，问题就解决了。

完成修改并重新压缩文件后，登录 claude.ai，进入你的账户设置，找到“能力”（Capabilities）选项卡。在这里，你会看到一个专门用于“技能”（Skills）的部分，旁边有一个“上传”（Upload）按钮。点击它，选择你刚刚创建的 `.zip` 文件进行上传。上传成功后，这个技能就会出现在你的技能列表中，并且你可以通过开关来启用或禁用它。

一旦技能被启用，你就可以在任何聊天中调用它。有趣的是，你甚至不需要使用确切的技能名称。例如，我上传了“demo-to-follow-up-email”技能后，在一个新的聊天窗口中，我输入：“嘿 Claude——我刚刚添加了‘demo-to-follow-up-email’技能。你能用它做点什么神奇的事情吗？” Claude 立即理解了我的意图，并开始执行技能中定义的任务，它会读取技能文档，理解其能力，然后开始工作，比如创建一个演示场景，然后将其转化为一封有竞争力的跟进邮件。你只需要提供相关的上下文，比如最新的更新日志，Claude 就能根据技能中的指令，自动完成剩下的工作。
